# Charter 设计规范（现行）

> **唯一依据是 Figma 文件 [Charter](https://www.figma.com/design/wZfK0kIMBZWCxBYAtlxxa5/Charter)。**
> 颜色、字体、间距、圆角、立体边、图标和全部组件以 Figma 为准；本文件只记录 Figma 画不出来的规则（语气、交互约定、双平台差异）。
> Figma 与本地文件冲突时，以 Figma 为准，再更新本地副本和代码。

## 0. 在哪里看什么

| 内容 | 位置 |
|---|---|
| 颜色、字体、间距、圆角、立体边、图标 | Figma · Foundations（变量集合 Color 含 Light / Dark 两个模式） |
| 组件 | Figma · Actions / Inputs / Status / Navigation / Data / Feedback / Structure |
| 每个版本的设计稿 | Figma · `5.x · …` 页面（标“已上线”的为现状） |
| 令牌快照 | `规范/figma-tokens.light.json`、`figma-tokens.dark.json`（2026-11-12 从 Figma 读取） |

| 视觉体系来源与动效、布局说明 | `规范/charter-grove/`（Figma 初稿时期的导出，数值以 Figma 为准） |
| 已废弃的经典 / 柔和双风格规范 | `规范/_archive/2026-10-双风格/`（仅作历史，不再遵循） |

**界面只有一种风格**（5.1 起）。可调的只有信息密度：舒适 / 紧凑，按这台电脑记住。

## 0.1 每一轮改动的流程

1. 先在 Figma 新建 `5.x · <主题>` 页面出稿，组件只用 Figma 组件库里的实例和变量。
2. 新组件或新变量先进组件页 / Foundations，再用于页面。
3. 实现时 `styles.css` 变量与 Figma 同名同值；写死的颜色、字号、圆角不允许新增。
4. 上线后把该页面标为“已上线 5.x.x”，被取代的标“已被 5.x.x 取代”。

## 0.2 Foundations 速览（以 Figma 为准）

- 字体：标题 Nunito 900/800，正文 Inter，中文回落苹方。字号阶梯：Display 32/42、Headline 23/31、Title 19/27、Figure 29/35、Subtitle 15/21、Body 13/20、Meta 12.5/18、Small 12/17、Label 12/15、Button 13/18、Pill 12/15。最小 12；唯一例外是法域徽章 XS（9.5）。紧凑密度见 Figma Typography 集合的“紧凑”模式（Display 26、Figure 24）。
- 颜色语义：绿只给可操作和“正常”；琥珀 = 需要处理；红 = 逾期；蓝 = 提示与识别来源；紫 = 个人。集团色 group/01–12 不含红橙黄绿。
- 间距 4 的倍数；描边统一 2px。圆角：胶囊 8、输入框 10、按钮与导航 12、数字卡 16、卡片 20、大徽标 24。
- 立体感 = 可以按：只有按钮（4px 底边）、徽标（6px）、结构图节点有底边；阴影只给弹窗、菜单、轻提示（Overlay）。
- 图标：Lucide 线性，24 网格、2px 描边，颜色跟随父级文字色。

## 1. 产品定位与语气

- Charter 是集团公司档案管家，用户是管理十几家境外公司的法务、公司秘书和财务。Charter 5 的三个承诺：**随问随答、到期不漏、知道找谁**。
- 事项只有两种状态：未完成、已完成。没有“请补发”“合规开关”“内部部门”这些概念。
- 界面全中文。公司名、人名保留原文；中文句子里夹英文名时，两侧各补一个空格（`latinPad`）。
- 文案写成指令或事实，读完就知道下一步。不道歉，不写营销腔。按钮写动作，结果提示沿用同一个动词：按钮“归档新版”，提示“已归档”。
- 出错说明三件事：发生了什么、数据有没有受影响、怎么办。
- 空状态给出下一步动作。
- 不用确认弹窗，用撤销：删除、移出等操作直接执行，提示条带“撤销”（6 秒）。
- 日期显示为“2026年10月13日”或“10月13日”；表格里的日期用等宽 `yyyy-MM-dd`。百分比用 `percentLabel`。


## 4. 交互约定

**快捷键**（Mac 用 ⌘，Windows 用 Ctrl）：

| 快捷键 | 功能 |
|---|---|
| K | 搜索公司或人 |
| , | 设置 |
| 1–6 | 结构、到期、中介、公司、文件、人员 |
| \ | 收起 / 展开侧栏 |
| ⇧N | 新建公司 |
| I | 上传材料 |
| Z / ⇧Z | 撤销 / 重做 |
| F | 当前页搜索 |
| ↑ ↓ | 在列表中切换 |
| Esc | 关闭 |

- **可点标签**（4.4）：凡是显示一个可修改属性的标签（法域、实体类型、集团、状态、职务、核实状态、“此事项单独指定”、“推算”），点它就地弹出选择，改动记入历史、可撤销。标签右侧带一个小下拉箭头。由数据算出来的标签（剩余天数、文件有效期）不算，点它跳到能改的地方。
- **新建主体**：法域没有默认值，必须明确选；名称后缀只给建议，要点一下才算选；保存前预览全称、法域、实体类型、集团。股东可以先不知道（“股东待补”），上层公司可以不属于任何集团。
- **结构图**：已核实的持股实线，待核实的虚线（与高亮链路无关）；历史视图里生效日期未知的关系标“最晚自”。
- 复选框是方角，单选是圆形。
- 右键菜单与行尾“⋯”菜单内容一致。
- 拖放：拖到某家公司（公司页、信息卡、文件页公司卡）直接归档到那家公司；目标卡片描 2px 墨色框、轻微内缩，顶部出一行黑色提示。
- 不用确认弹窗，用撤销（§1）。批量写入前先保存本地快照。

## 5. 双平台差异

- 文案中性：“这台电脑”；Windows 写“在资源管理器中显示”，Mac 写“在访达中显示”。
- 同步盘统称“同步盘”（iCloud 云盘、OneDrive 等）。
- 标题栏：Mac 透明，顶部留 28px 拖拽区；Windows 原生标题栏，顶部留 6px。
- 日历：在数据文件夹生成 `.ics` 供订阅，不直接写系统日历。
