# Charter 设计规范（Charter 5 · Electron）

本规范是 Charter 桌面版（Electron，Mac + Windows）的唯一设计依据。4.x 的 Tauri 源码保留在 `desktop/src-tauri/`，其中的历史交互规则仍可作为兼容参考。数值在 `tokens.json`，实现在 `desktop/src/ui/styles.css`；本文件夹（`规范/`）放全部设计规范：`DESIGN.md`、`tokens.json`、`MOTION-REVIEW.md`、`PROPOSAL-TEMPLATE.md` 和每一轮的 `proposals/`。代码和规范冲突时，先改规范再改代码，两者在同一次提交里对齐。

Charter 有两种界面风格：**经典**和**柔和**。两种风格**同一结构、两套外观**：功能、信息、页面骨架和交互完全一致，只在颜色、字号、卡片切法上不同。用户在设置 → 数据与同步 → 界面风格里切换，按这台电脑记住，即时生效。

## 0. 两个设计团队怎么一起出方案

### 0.1 分工

| | 经典团队 | 柔和团队 |
|---|---|---|
| 一句话 | 黑白骨架，一个柠檬绿强调 | 颜色说是谁，数字说多急，一张卡只说一件事 |
| 负责 | §4 经典外观；守住信息密度和扫读效率 | §5 柔和外观；守住色块、数字、拼块的一致性 |
| 共同负责 | §1 语气、§2 共同骨架、§3 语义色、§6 尺寸、§7 动效、§8 交互 | 同左 |

- 两个团队对**共同骨架**（§2）有同等否决权：任何一方提出的结构性改动（新增区块、换位置、加数字），必须两种外观都画出来、都成立，才能进骨架。
- 外观层（§4、§5）各自做主，但不得改变信息和操作：同一屏上，经典能看到、能点的，柔和也必须能看到、能点，反之亦然。
- 某个元素只适合一种外观时，另一种外观必须给出等价表达（例：柔和的“票据”在经典里是“日期列 + 状态胶囊”的普通行）。

### 0.2 每一轮方案的流程

1. **对齐问题**：用引导选择框和用户逐项对齐，范围、取舍、推荐项写在前面。
2. **骨架草图**：先定这一屏的共同骨架（区块、顺序、数字、操作），写进本文件 §2。
3. **两套外观**：两个团队各画一张画板，同一份数据、同一个状态、同一个选中项。
4. **成对评审**：两张画板左右并排，按 §0.4 的清单逐项过。
5. **更新规范**：§2 / §4 / §5 / `tokens.json` 和画板在同一轮更新，再进入实现。
6. **实现与验收**：实现后两种风格各截一张实机图，与画板对照。

### 0.3 交付标准

每一轮方案必须交付：

- **画布上成对的画板**：
  - 命名：`<编号> <屏名>·经典`、`<编号> <屏名>·柔和`，左右相邻（经典在左，x 相差 1520）。
  - 尺寸 1440×900；同一份示例数据（Harbor Crest / 明岸 / 远澜集团、17 家公司）。
  - 每张画板最多 3 条紫色批注，只写“为什么这样做”，不复述画面。
  - 新的结构性元素在两张画板上用同一条批注编号对应。
- **规范同步**：本文件对应章节、`tokens.json`。改了骨架必须改 §2；新组件必须写进 §4 和 §5 各一条。
- 交付时说明：哪些是骨架改动、哪些只是外观改动、还有哪些屏没画。

### 0.4 成对评审清单

- [ ] 两张画板的信息完全一致（数字、名称、状态、操作）。
- [ ] 每屏只有一个最大的数字或标题，两种外观选的是同一个。
- [ ] 状态色只表达状态（§3.1），集团色只表达归属（§3.2）。
- [ ] lime 的用法符合各自外观的规则（经典 §4.2 / 柔和 §5.2）。
- [ ] 柔和：卡片无描边、无分隔线；着色卡上没有 lime 描边或光晕；没有集团小圆点和着色并存。
- [ ] 经典：白卡 + 细线层级；不出现大面积集团色铺底。
- [ ] 选中态：两种外观都是墨色（经典墨色实底，柔和墨色实底或 2px 墨色描边）。
- [ ] 深色模式下两种外观都检查过对比度（正文 ≥ 4.5:1，大数字 ≥ 3:1）。
- [ ] 文案一致，按钮动词与结果提示一致（§1）。

## 1. 产品定位与语气

- Charter 是集团公司档案管家，用户是管理十几家境外公司的法务、公司秘书和财务。Charter 5 的三个承诺：**随问随答、到期不漏、知道找谁**。
- 事项只有两种状态：未完成、已完成。没有“请补发”“合规开关”“内部部门”这些概念。
- 界面全中文。公司名、人名保留原文；中文句子里夹英文名时，两侧各补一个空格（`latinPad`）。
- 文案写成指令或事实，读完就知道下一步。不道歉，不写营销腔。按钮写动作，结果提示沿用同一个动词：按钮“归档新版”，提示“已归档”。
- 出错说明三件事：发生了什么、数据有没有受影响、怎么办。
- 空状态给出下一步动作。
- 不用确认弹窗，用撤销：删除、移出等操作直接执行，提示条带“撤销”（6 秒）。
- 日期显示为“2026年10月13日”或“10月13日”；表格里的日期用等宽 `yyyy-MM-dd`。百分比用 `percentLabel`。

## 2. 共同骨架（两种风格必须一致）

### 2.1 窗口

- 左侧导航 + 右侧主区。导航从上到下：Logo（点它收起/展开，仅经典）、⌘K 搜索、结构 / 到期 / 中介、档案分组下的公司 / 文件 / 人员、设置。
  - 经典：250px 带文字，可收起为 64px 图标栏（⌘\），收起时悬停 300ms 出预览卡。侧栏下方是“接下来 90 天”列表。
  - 柔和：固定 76px 图标栏，悬停 300ms 出预览卡；“接下来 90 天”收进到期图标的预览卡和到期页数字条。
- 设置是居中浮层，分组：常规（数据与同步、提醒）、公司资料（集团、档案清单、文件包用途）、到期规则（合规规则）、高级（备份与恢复）。

### 2.2 每页顶部：标题 + 数字条

每页标题下是一排 2–4 个数字，回答“这一页今天要不要处理”。需要处理的数字可以点，直接跳到对应列表。

| 页面 | 数字（从左到右） |
|---|---|
| 结构 | 已逾期 · 30 天内 · 在管公司 · 待核实 |
| 到期 | 已逾期 · 30 天内 · 范围内共 |
| 中介 | 中介 · 指定了默认中介的公司 · 经手的待办事项 |
| 公司 | 在管公司 · 集团 · 档案待补 · 待核实 |
| 待核实 | 待核实 · 已核实 · 缺依据文件 ·（其中从 4.3 迁移） |
| 文件 | 现行文件 · 已过期 · 90 天内到期 · 缺少 |
| 人员 | 人员 · 在任董事和高管 · 任职 |

### 2.3 各页骨架

（4.4 起）**每条股权和任职都带出处**：生效日期（可未知）、资料截至日期、录入日期（自动）、依据（档案里的文件 + 页码）、核实状态（已核实 / 待核实，已核实必须有依据）。录入时先问“新发生的变更 / 补录已有事实”，生效日期早于 30 天或未知时默认补录；**补录不生成任何变更类提醒**。职务按法域角色表选（`desktop/src/domain/roles.ts`），角色归入所有者 / 管理者 / 秘书与代表三类，界面显示本地名称。

1. **结构**：数字条 → 集团切换条（全部 + 各集团，右侧历史、缩放、更多）→ 股权图画布。选中公司后右侧出信息卡（380px），内容依次：身份（法域、名称、集团、编号）、下一件到期（天数）、上层持股（%）、档案进度、董事和高管、平行公司、默认中介、操作（打开公司 / 复制摘要）。选中人员时右侧出穿透持股列表。
2. **到期**：左侧事项列表（按月分组，范围 90 天 / 一年 / 全部）；右侧详情，依次：
   - 头部：公司、事项名、截止日、**剩余或逾期天数（本屏最大的数字）**、日期确认（推算 / 已确认，可改）。
   - 找谁办：中介、主对接人、复制邮箱、换一家中介；**这家中介手上还有几件（其中几件逾期）**。
   - 邮件草稿（可改）。
   - 操作：复制邮件、标为已完成（含“附上回执并完成”）。
3. **中介**：左侧中介列表；右侧详情：名称与说明、对接人（多位，第一位为主对接）、默认负责的公司、负责的事项。
7. **待核实**（从结构、公司页的数字条或公司页头“N 条待核实”进入，不在导航里）：按公司分组列出待核实的股权和任职；每行选依据文件、填页码，选了文件才能“标为已核实”。

4. **公司**：左侧公司列表（按集团分组、按持股层级缩进，缺档案的标出）；右侧公司页：
   - 页头：法域、名称、标签（法域名、集团、实体类型、编号），**三个数字：档案 x/y、下一件到期（天）、上层持股（%）**；操作：复制摘要、更多。
   - 页头标签都能点：法域、实体类型、集团（含“不属于集团”，可多选）、状态。
   - 股东、董事和高管每行：比例或职务（职务可点改）、核实状态（可点：已核实 / 待核实 / 关联依据…）、第二行写“生效 x · 截至 y”或“生效日期未知 · 最晚自 y”和依据文件。添加时打开录入表单。没有股东时显示“股东待补”。
   - 变更历史每条写生效、录入日期和“补录”标记；生效日期未知的可以补。
   - 两栏：左栏基本信息、股东、董事和高管、变更历史；右栏到期事项、档案清单、默认中介。所有字段就地编辑，改动记入历史。整页可拖入文件归档。
5. **文件**：每家公司一张卡（份数 x/y、分段进度条、最要紧的两条）；可切换按类型、人员文件、缩略图；右侧“需要处理”列表（过期和 90 天内到期，每条带“归档新版”）。
6. **人员**：左侧人员列表；右侧详情：任职、持股、个人文件。

## 3. 语义色（两种风格共用含义）

### 3.1 状态

- **已逾期 / 已过期**：红（经典 `danger`，柔和 `rose`）。
- **30 天内 / 需要处理 / 快到期**：琥珀（经典 `amber`，柔和 `butter`）。
- **完成 / 有效**：经典用 `limeSoft` 浅底 + `limeText`；柔和只在“完成”那一刻闪现 lime，平时有效不着色。
- 颜色不单独表达含义：状态同时有文字（“已逾期 17 天”）或图形。

### 3.2 集团

- 每个集团有一个自选色（18 个预设 + 自定义）。集团色只表达**归属**，不表达状态。
- 经典：集团色只出现在小圆点和集团切换条上。
- 柔和：集团色推出浅底（18–20% 混底色）和文字色（62% 混墨色），铺满该公司出现的卡片、节点、代码块；不再画小圆点。共用公司是白卡。

### 3.3 选中与焦点

- 选中：墨色。经典墨色实底；柔和列表项墨色实底，着色卡片/节点用 2px 墨色描边加抬起阴影。
- 键盘焦点：2px 墨色外框，偏移 2px。

### 3.4 文件与档案状态（4.5）

一条档案条目或一份文件同时有两个维度：**有没有**（获取）和**能不能用**（有效性）。核实、签署是附加标记。

| 状态 | 文字 | 图标 | 颜色（柔和） | 使用条件 |
|---|---|---|---|---|
| 已归档 | 已归档 | 实心对勾圆 | 墨色字，无底色 | 有现行文件（未被替代） |
| 现行 | 现行 | — | — | 文件未被替代；只在同类有旧版时显示，用来和“旧版”区分 |
| 旧版 | 旧版 | 时钟回绕 | 灰字 | 文件被另一份替代（`supersededBy`） |
| 已签署 | 已签署 | 笔 | 墨色字 | 类型要求签署且已签署（D1） |
| 已核实 | 已核实 | 盾牌对勾 | 墨色字 | 与原件核对过（D2）；股权/任职沿用 4.4 |
| 快到期 | N 天后到期 | 沙漏 | 琥珀底 | 30 天内到期 |
| 已过期 | 已过期 N 天 | 感叹三角 | 玫瑰底 | 过了到期日 |
| 缺日期 | 缺日期 | 问号 | 琥珀描边 | 有效期依赖日期但没填 |
| 需更新 | 需更新 | 刷新 | 琥珀描边 | 公司信息变了，文件内容可能过时 |
| 待取得 | 待取得 | 空心圆 | 灰描边 | 标记为“未取得”或缺件未标记 |
| 不适用 | 不适用 | 斜杠圆 | 灰字，删除线不用 | 标记为不适用；不计入 x/y |
| 外部保管 / 权限受限 | 原文字 | 锁 | 灰字 | 原标记，计入“已有”但无本地文件 |

规则：状态标签 = 图标 + 文字，颜色只是加强；同一行最多一个风险标签（取最急的），核实/签署作为附加小标签放在后面。


## 4. 经典外观（经典团队）

### 4.1 基调

- **黑白骨架，一个柠檬绿强调。** 灰底 `canvas`、白色 `surface` 卡片、墨色文字；层级靠白卡、细线（`hairline`）和字重。
- 深色模式按 `prefers-color-scheme` 切换，`:root[data-theme]` 可强制；令牌见 `tokens.json → color.dark`。

### 4.2 lime 的用法

只在四处出现：结构图里高亮的控制链（连线底衬 + 比例标签 + 节点光晕）、“有效/完成”状态（`limeSoft`）、Logo、完成事项那一刻的勾。不用作描边装饰。

### 4.3 组件表达

| 共同骨架里的元素 | 经典表达 |
|---|---|
| 数字条 | 标题下一行，白底小卡或纯文字数字（22–28 / 600），需要处理的数字用琥珀/红色字 |
| 公司页头三个数字 | 页头右侧三列：小标签 + 28 / 600 数字 |
| 到期详情天数 | 头部右侧 44 / 800 等宽数字（display） |
| 到期事项 | 普通行：日期列（日 + 周几）+ 法域代码 + 事项名 + 状态胶囊 |
| 信息卡 | 一张长卡，区块之间留白，不分块 |
| 集团归属 | 名称前的小圆点 |
| 档案进度 | `x/y` 文字 + 每项状态点 |

### 4.4 字体

| 名称 | 字号与字重 | 用途 |
|---|---|---|
| display | 44 / 800，字距 -1.3，等宽数字 | 到期详情天数 |
| pageTitle | 28 / 800 | 页面标题 |
| title | 22 / 700 | 公司名、人名 |
| sheet | 22 / 800 | 弹窗、设置标题 |
| section | 15–17 / 600 | 区块标题 |
| rowTitle | 14 / 600 | 列表行主文字 |
| body | 14 / 400，行高 1.45 | 正文 |
| meta | 12.5 / 500 | 次要信息 |
| micro | 11 / 500 | 分组小标题（不全大写） |
| mono | ui-monospace | 编号、日期 |

## 5. 柔和外观（柔和团队）

### 5.1 基调：六条

1. **集团色铺整块，不点缀。** 公司出现在哪里，就用它集团的浅底铺满那张卡或那颗节点；不再有小圆点、彩色描边。共用公司是白卡。
2. **状态只有两种暖色。** 琥珀 `butter` = 30 天内，玫瑰 `rose` = 已逾期。只出现在事项和数字上，从不给公司卡上色。
3. **数字是主角。** 天数、件数、份数、持股用 250 字重的大数字，单位小而粗；打开页面先读到数字。
4. **一张卡一件事。** 卡片按问题切（下一件什么时候、谁来办、档案齐不齐），每张卡最多一个操作。
5. **黑色只给“你在哪”和“下一步”。** 选中项、主按钮用墨黑胶囊；lime 只在“完成”那一刻闪现。
6. **没有线。** 不描边、不画分隔线；层级靠 10px 卡缝和画布灰。白色卡片里的子卡用 `band` 浅灰底。

### 5.2 lime 的用法

只在两处：Logo、完成那一刻（勾和闪现）。结构图链路用墨色连线、墨底白字比例标签，链路外节点淡到 55%；选中节点 2px 墨色描边 + 抬起阴影。**着色卡片上永远不加 lime 描边或光晕。**

### 5.3 组件表达

| 共同骨架里的元素 | 柔和表达 |
|---|---|
| 数字条 | 一排数字卡（圆角 24，内距 16/18）：标签 12 / 600 + 大数字 44–52 / 250 + 单位 13 / 700；需要处理的卡整块 `rose` / `butter` 底 |
| 公司页头三个数字 | 整张头卡铺集团色，右侧三个 52 / 250 大数字 |
| 到期详情天数 | 头卡整块跟状态换底色（逾期 `rose`、30 天内 `butter`、其余白），天数 96–104 / 250 |
| 到期事项 | 票据：左侧日期票根（日 24 / 300 + 月 11，逾期红、30 天内琥珀）、虚线隔开、上下各一个缺口；缺口颜色 = 所在底色 |
| 信息卡 | 拼块：集团色头卡 → 两格大数字（下一件到期、上层持股）→ 档案 → 董事 → 默认中介 → 底部固定操作 |
| 集团归属 | 卡片/节点/代码块整块浅底 |
| 档案进度 | 分段进度条：墨 = 有效，玫瑰 = 过期，琥珀 = 快到期，空 = 缺 |
| 文件页公司卡 | 整卡集团色，份数大数字 + 分段进度条 + 最要紧的两条 |

### 5.4 字体

| 名称 | 字号与字重 | 用途 |
|---|---|---|
| hero | 72–104 / 250，字距 -0.04em | 每屏唯一的最大数字（到期详情天数） |
| big | 40–56 / 250 | 数字卡、信息卡、页头三个数字 |
| pageTitle | 30 / 800，字距 -0.6 | 页面标题 |
| cardTitle | 15 / 600 | 卡片主信息 |
| label | 12 / 600 灰 | 卡片标签（是问题，不是装饰） |

## 7. 动效与交互流畅度（两种风格共用）

### 7.0 动画行为表（4.5，优先于本章其余条目）

时长：instant 80 / fast 120 / standard 200 / panel 280。缓动：进入 `cubic-bezier(.2,.8,.2,1)`，离开 `cubic-bezier(.4,0,1,1)`。全部用 transition（可被下一次改变直接中断，从当前值继续），不用 keyframe 排队。

| 场景 | 触发 | 属性 | 时长 / 缓动 | 中断 | 减少动态效果 |
|---|---|---|---|---|---|
| 按钮、标签按下 | pointerdown | scale 0.98、背景 | instant / 进入 | 抬起即恢复 | 只变背景 |
| 选中切换（导航、集团筛选、分段、列表） | 点击、方向键 | 共享底块 transform、width | standard / 进入 | 新目标直接接管当前位置 | 无位移，直接到位 |
| 列表行选中 | 点击、方向键 | 背景、文字颜色 | fast | 立即 | 同 |
| 页面切换 | 点导航 | 无动画（只换内容） | — | — | — |
| 公司详情切换 | 选另一家公司 | 内容区 opacity 0.6→1；头部和布局不动；滚动回到顶部只在换公司时 | fast | 新内容直接替换 | 无 |
| 面板开合（信息卡） | 选中/取消 | opacity + translateX 12px | panel 开 / fast 关 | 反向立即 | 只 opacity |
| 弹窗 | 打开/关闭 | 背景 opacity；面板 opacity + translateY 8px | standard 开 / fast 关 | 关闭时可再次打开 | 只 opacity |
| 菜单、气泡 | 打开/关闭 | opacity + translateY 4px | fast / instant | 同 | 只 opacity |
| 结构图筛选 | 切集团 | 节点 opacity；视野自动适配（缩放到合适窗口） | standard | 再切换直接重算 | 无过渡，直接到位 |
| 结构图布局变化 / 历史 | 年份、重排 | 节点位置逐帧补间（JS），连线跟随 | panel | 新目标从当前中间位置继续 | 直接到位 |
| 结构图缩放按钮 | 点 +/− | 比例补间，锚点视口中心 | standard | 连续点击从当前值继续 | 直接到位 |
| 选中节点后视野调整 | 选中不在视野内的节点 | scroll | 平滑 | 用户滚动即取消 | 不自动滚动，只高亮 |
| 上传 / 识别 | 拖入、选文件 | 300ms 后才出现忙碌标签；进度条 width | standard | 完成立即消失 | 进度条无过渡 |
| 归档完成 | 归档成功 | 印章（仅导入完成页）、行高亮 1s | long / standard | — | 只高亮 |
| 成功 / 失败提示 | 操作后 | opacity + translateY 8px | standard 进 / fast 出 | 新提示替换旧提示 | 只 opacity |
| 撤销 | 点“撤销” | 恢复的行高亮 1s | — | — | 同 |
| 完成事项 | 标为已完成 | 打勾 → 行 opacity 0（fast），**数据立即更新**，动画在残影上播放 | fast | 不阻塞下一次操作 | 无残影 |

约束：动画不移动正在点击的目标（不对按钮做位移），不抢输入焦点，不重置用户的滚动位置；弹窗关闭后焦点回到打开它的按钮。


### 7.1 基本原则

1. **快于思考**：任何操作 100ms 内要有看得见的反馈。动效是在说明“发生了什么”，不是装饰。
2. **只回应操作**：动效只跟着用户的动作出现。不做自动播放、呼吸灯、进场时逐块上浮。
3. **先显示，后保存**：编辑、勾选、删除都立即反映在界面上，写盘在后台进行。失败时回滚，并用提示条说明。
4. **进来慢一点，出去快一点**：出现用 standard 或 panel 档，消失用 fast 档。
5. **一个变化只动一处**：同一时刻不让多个区域同时位移。

### 7.2 时长与曲线（`tokens.json` → CSS 变量）

| 变量 | 时长 | 用于 |
|---|---|---|
| `--instant` | 80ms | 按下反馈、消失 |
| `--fast` | 120ms | 悬停、勾选、颜色变化、菜单收起 |
| `--standard` | 200ms | 选中滑动、展开收起、开关、分段控件、整页淡入 |
| `--panel` | 280ms | 弹窗、设置浮层、信息卡、提示条出现 |
| `--long` | 900ms | 只给归档印章这类“完成时刻”，一屏最多一个 |

- **曲线**：
  - `--ease: cubic-bezier(.2,.8,.2,1)`：出现、移动用，起步快、收尾轻。
  - `--ease-out: cubic-bezier(.4,0,1,1)`：消失用。
- **禁止**：在组件里直接写 `.2s`、`ease`、`linear`，必须用上面这些变量。只有加载转圈可以用 `linear`。

### 7.3 响应速度

| 情况 | 要求 |
|---|---|
| 点击、按键 | 100ms 内有反馈（按下态、选中态、光标） |
| 本地操作（改字段、勾选、删除、切换页面） | 立即完成，不显示加载 |
| 读文件、识别证书、打包导出 | 300ms 内显示进度（转圈或进度条），并写明在做什么，如“正在识别…” |
| 超过 3 秒 | 显示阶段文字或百分比，并允许取消 |
| 失败 | 恢复原状，提示条写清原因和下一步，不弹对话框 |

骨架屏只用于首次读取数据文件夹，其余场景不用。

### 7.4 组件动效

**按钮**
- 悬停：底色变化，用 fast。
- 按下：缩到 0.98（只给按钮和标签，不给行），用 instant；松开时回弹，用 fast。
- 禁用：没有任何动效。

**列表行、导航项、选中态**
- 悬停底色用 fast。
- 选中切换：底色直接到位。分段控件和集团切换条用“底色滑动”，standard。

**开关、勾选**
- 圆点滑动和底色同步，standard。
- 勾号用 fast 淡入。

**菜单、下拉、气泡**
- 出现：从锚点方向位移 4px，加透明度和 0.98 缩放，fast。
- 消失：只做透明度变化，instant。

**弹窗、设置浮层**
- 出现：背景遮罩淡入 standard；面板上浮 8px，panel。
- 消失：遮罩和面板一起淡出，fast。
- 打开后焦点落到第一个输入框或主按钮；Esc 关闭。

**信息卡、右侧详情**
- 首次出现：从右侧 12px 淡入，panel。
- 切换选中对象时不重新滑入，只把内容淡入一次，standard。

**提示条（toast）**
- 出现：从底部 16px 升起，panel。
- 停留 4 秒，悬停时暂停计时；带“撤销”的停留 6 秒。
- 消失：下沉 8px 加淡出，fast。
- 新的一条直接替换旧的，不叠加。

**就地编辑**
- 悬停显示浅底，fast。
- 进入编辑：变成白底加 1.5px 黑色描边，fast，光标定位到点击处。
- 回车或失焦保存，Esc 放弃；保存后描边立即消失。

**列表增删**
- 新增的一行：浅色底高亮 1 秒，再用 standard 淡回。不做展开动画。
- 删除：这一行淡出，fast，下面的行直接补位。撤销恢复时按“新增”处理。

**拖放**
- 文件拖进可放置区域：边框变成 2px 黑色，并显示“松开即可归档到…”，fast。
- 松手：识别过程中显示转圈；完成后用提示条反馈。区域本身不做动画。

**结构图**
- 缩放、平移跟手，不加缓动。用按钮缩放时用 standard。
- 选中节点：节点描边和持股链路高亮同时出现，fast；若节点不在视野里，平滑滚到可见，standard。
- 切换集团、打开历史：整图淡入一次，standard。时间轴回放每一步之间停 1.4 秒，节点位置变化用 panel。
- 拖动节点：跟手；松手时直接落位，不回弹。

**归档完成印章**
- 圆环 0.9 秒画出，圆点 0.3 秒弹出，只在这一处使用 long。

#### 7.4.1 4.2 起的补充（来自 MOTION-REVIEW.md）

- **选中底块滑动**：侧栏导航、集团切换条、分段控件、历史时间轴共用一块黑色底块（`SlideBg`），在项之间滑动（standard）。首次出现、窗口尺寸变化时不滑。
- **页面切换**：整页淡入 + 上移 4px（standard），每次切页只播一次。
- **侧栏图标栏**：点左上角 C 或 ⌘\ 收起为 64px 图标栏（panel 档宽度过渡），状态记住。收起后悬停图标 300ms 弹出白底预览卡；在图标之间移动时卡片滑过去（standard）并淡入新内容，不关再开；移开 160ms 后消失。展开时不弹。
- **离场**：菜单、气泡、页内确认框关闭时淡出（fast，ease-out）；被删除的行原地淡出（公司页、中介对接人、设置里的集团、成员、档案清单、规则、法域列表）；选中的新行不加高亮；撤销恢复的行按新增处理（1 秒浅色高亮）。
- **结构图**：选中后立即滚到可见；用按钮缩放时比例与位置一起过渡（standard），捏合和滚轮保持跟手；切换集团整图淡入；历史回放时节点位置逐帧补间（panel），连线和比例标签按中间位置一起重画，新出现的节点和连线淡入；节点悬停上移 1px。
- **换内容**：信息卡、公司页换公司时内容淡入（standard），卡片本身不动。
- **完成事项**：这一行先打勾，280ms 后淡出，再移出列表；件数用数字过渡（600ms），只在操作后动。
- **拖放**：卡片描 2px 黑框、内缩到 99.5%，顶部出黑色提示条（fast）。不再整块盖 lime。

### 7.5 减少动态效果

系统打开“减少动态效果”时：
- 所有位移和缩放取消，元素直接到位。
- 透明度变化保留，统一用 fast。
- 印章直接显示完成状态，结构图滚动改为直接跳转。
- 加载转圈保留。

### 7.6 焦点与键盘

- 用键盘移动焦点时，显示 2px 黑色焦点环，外偏移 2px，直接出现、不做动画。鼠标点击不显示焦点环。
- 上下键切换列表时，选中项跟随滚动，保持在可见范围内。
