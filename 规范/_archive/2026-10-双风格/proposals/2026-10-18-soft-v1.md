# 柔和提案 v1（2026-10-18）

## 1. 要解决什么

- 用户原话：“柔和模式下还是感觉像是半成品移植来的……假设是 Charter 里的另一个专家设计团队，来一份设计。”
- 涉及的屏：设计原则、结构、到期、公司、文件。
- 不做什么：本轮不实现，不出新版本。

## 2. 对齐结果

| 问题 | 用户选择 |
|---|---|
| 柔和版侧栏 | 固定窄图标栏（76px），悬停出预览卡 |
| 文件页 | 两种风格都改成“每家公司一张卡” |
| 两支团队分工 | 同一结构、两套外观 |
| 交付标准 | 画布上经典/柔和成对画板 + 规范同步更新 |
| 并入共同骨架 | 每页顶部数字条；公司页头三个数字；到期详情大天数 + 中介手上件数 |
| 不并入骨架 | 信息卡拼块（只属于柔和外观；经典保持一张长卡） |
| 经典结构图链路 | 保留 lime |
| 柔和深色模式 | 要，令牌先定（DESIGN.md §5.5） |

## 3. 共同骨架改动

| 元素 | 经典 | 柔和 |

| 数字条 | 白底小卡或纯文字数字，需处理的用琥珀/红色字 | 大数字卡，需处理的整卡 rose/butter |
