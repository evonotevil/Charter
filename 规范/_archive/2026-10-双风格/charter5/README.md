Charter 是法务和公司治理人员用的公司档案工具：一个人要长期管理几十家、跨多个法域的公司，核对它们的股权、任职、法定文件和合规截止日。Charter 5 从零重新设计，目标只有一个：**每家公司一个工作区，每项义务一个去处，每个数字都能追到原文件。**

## 设计原则

1. **一家公司，一个工作区。** 进入一家公司后，侧栏换成它自己的导航（概览、股权结构、文件、合规、变更历史），公司头部固定不动。跨公司的工作（结构图、合规总览、目录）留在全局侧栏。
2. **先事实，后叙述。** 公司头部下面先放事实条（法域、注册编号、成立日期、股本、商业登记号），再放卡片。空着的字段写「未填」，让缺口可见。
3. **结构从数据里长出来。** 股权结构图不手画，由股东记录生成；打开时一层一层长出，让人看清“谁持有谁”。
4. **一种状态，一个词，一种样子。** 已完成、办理中、逾期、待办理、不适用，在徽章、看板、计数、筛选里用同一个词、同一个图标、同一个颜色。
5. **每条结论都有出处。** 识别出的字段指回原文件；每个合规事项写明依据的条例和规则编号。
6. **同一份数据，按需要的方式看。** 合规事项可以看时间线、看板、表格；公司目录可以看卡片、表格。切换看法不改变筛选和范围。
7. **安静，可以连续工作几个小时。** 颜色只用来表达状态和类别；动效只在回应操作或展示变化时出现，不装饰。

## 文案

- 用户是专业人员：用他们的术语（周年申报表、商业登记证、重要控制人登记册、公司秘书），不用系统内部名词。
- 句子短，主动语态，中文全角标点；英文公司名、条例名保持原文。
- 按钮写动作和结果：「生成合规清单」「指派并通知」「导出摘要」。不用「提交」「确定」「OK」。
- 回执用同一个动词：「导出备份」→「已导出备份：23 家公司，412 份文件」。
- 空状态说清缺什么、从哪份文件能找到：「还没有董事。从公司注册处的周年申报表里可以找到董事名单。」
- 错误说清发生了什么、怎么办：「没读到到期日，请手动填写」。不道歉，不写「出错了」，不显示 `undefined`。
- 日期一律 `YYYY-MM-DD`；相对时间写「还有 28 天」「逾期 19 天」。金额写币种代码：`HKD 10,000`。
- 不用表情符号，不用全大写标签。

## 视觉基础

**颜色。** 画布 `canvas` 是带一点蓝的冷灰，内容面 `surface` 是白。正文 `ink`，次要正文 `ink-2`，标签和元信息 `muted`；`faint` 只用于占位符和禁用。选中项和主按钮用墨色实底 `selected` + `on-selected`，这是整个界面里最重的颜色，只给“你在哪”和“下一步”。`accent` 只用于链接、焦点框、拖放目标和识别来源，不做大面积底色。

**状态色**（文字 / 底）：`ok` / `ok-soft` 已完成；`warn` / `warn-soft` 办理中、快到期；`bad` / `bad-soft` 逾期、已过期。每个状态都同时有图标和文字，颜色只是加强。

**类别色**：法人实体用 `accent` 系（标签 `accent-soft`、结构图描边 `entity-line`），个人用橙色系（`person-soft`、`person-line`）。集团色只用小圆点 + 集团名表达归属，不铺底、不改描边、不表示风险。

**字体。** 界面用 `sans`（IBM Plex Sans + 苹方）。公司名用 `serif`（Source Serif 4 + 宋体）——全系统只有公司名用衬线：工作区头部 `entity-title`（26/600，每屏一次），卡片和结构图节点 `entity-name`。注册号、编号用 `mono`。所有并排比较的数字用等宽数字。

| 样式 | 用途 |
|---|---|
| `page-title` 20/650 | 页面标题 |
| `section-title` 14/600 | 卡片标题 |
| `body` 13/20 | 正文、表格 |
| `meta` 12/18 | 次要信息 |
| `label` 11/600 | 字段标签 |
| `figure` 20/600 | 事实条的值 |
| `figure-xl` 30/600 | 合规完成度 |

**间距。** 4 的倍数：`space-1` 4 到 `space-6` 32。页面边距 24（`space-5`），卡片之间和卡片内边距 16（`space-4`），行内元素 8。

**圆角。** 有层级：标签 `radius-sm` 6，按钮、输入框、节点 `radius-md` 8，卡片 `radius-lg` 12，弹窗和窗口 `radius-xl` 16，筛选胶囊和轻提示 `radius-pill`。

**描边与阴影。** 静止的卡片只有 1px `hairline` 描边，没有阴影。`shadow-raised` 只在悬停和选中时出现；`shadow-overlay` 只给弹窗、菜单和轻提示。输入框和次按钮用 `hairline-strong`（≥3:1）。

**交互状态。** 悬停：底色换成 `surface-hover`（120ms）。按下：按钮和标签缩到 0.98（80ms），行不缩。键盘焦点：2px `accent` 外框，偏移 2px，只在键盘操作时出现。禁用：文字 `faint`，鼠标显示不可用，用 `title` 说明原因。选中：墨色实底，或 1px 墨色描边 + 1px 外环。

**密度。** 默认舒适（行高 44、控件 32）；紧凑（行高 36、控件 28、页面边距 16）供上百家公司批量核对。密度和深浅色互相独立。

**长内容。** 公司名最多两行，悬停显示全名；文件名一行截断；一人多职时名字写一次、职务逐行列出；缺失字段写灰色「未填」。

## 图标

自绘线性图标：16×16 网格、1.5px 描边、圆角端点，颜色继承文字色（见 `Icon`）。图标旁边一定有文字，纯图标按钮必须有 `label`。不用表情符号。

## 标志

Charter 标志是黑底圆角方块上的青柠色「C」（`brand-black`、`brand-lime`），见 Logos 资源组。青柠色只用于标志，不进入界面。
