# 动效规范

动效只做三件事：**回应操作**（按下了、选中了）、**说明变化**（哪里多了、少了、移到哪）、**展示进度**（还在处理）。不做装饰性的入场，不让用户等动画。

## 时长与曲线

| 名称 | 时长 | 用途 |
|---|---|---|
| instant | 80ms | 按下缩放、菜单消失 |
| fast | 120ms | 悬停、颜色变化、淡出、内容交叉淡化、小元素出现 |
| standard | 200ms | 选中底块滑动、弹窗和轻提示出现、视图切换 |
| emphasis | 280ms | 数值补间（进度条、完成环、持股条） |
| build | 360ms | 结构图里一条连线描出的时间 |

| 曲线 | 值 | 用途 |
|---|---|---|
| enter | `cubic-bezier(.2,.8,.2,1)` | 出现、展开 |
| exit | `cubic-bezier(.4,0,1,1)` | 消失、收起 |
| move | `cubic-bezier(.3,0,.2,1)` | 位置和数值从一处移到另一处 |

依次出现的间隔（stagger）40ms，最多 3 组；第 4 组以后同时出现。

## 规则

1. **可打断，不排队。** 全部用 transition，或能从当前值继续的补间；新的操作直接从当前中间状态接管，不等上一个动画结束。
2. **不移动正在点的东西。** 悬停不上移，按下只缩 2%，插入的内容不把用户正要点的按钮推走。
3. **不抢焦点、不重置滚动。** 动画期间输入框照常可打字；切换视图保留滚动位置（换公司时才回到顶部）。
4. **只动 opacity 和 transform。** 不对宽高、边距做动画（例外：进度条宽度、数值条宽度）。
5. **数据先更新，动画后播放。** 标记完成、删除这类操作，数据和计数立即变化，离场动画在残影上播放。
6. **减少动态效果。** 系统开启后：去掉所有位移、缩放、描线和依次出现，只保留 ≤120ms 的透明度变化；选中底块、数值条直接到位；结构图整张直接出现。

## 场景

| 场景 | 触发 | 属性 | 时长 / 曲线 | 打断 | 减少动态效果 |
|---|---|---|---|---|---|
| 按钮、标签按下 | pointerdown | scale 0.98、底色 | instant / enter | 松开即恢复 | 只变底色 |
| 悬停 | 指针进入 | 底色、描边、阴影 | fast | 立即反向 | 同 |
| 侧栏选中 | 点击、⌘1–6 | 墨色底块 translateY | standard / move | 新目标从当前位置接管 | 直接到位 |
| 分段控件、筛选胶囊 | 点击、方向键 | 底块 translateX + width | standard / move | 同上 | 直接到位 |
| 全局 ↔ 公司工作区 | 进入或离开公司 | 侧栏内容交叉淡化；主区域区块依次上浮 8px 淡入（头部 → 事实条 → 卡片） | fast；standard + stagger 40ms | 再次切换直接替换 | 只淡入 |
| 工作区子页面切换 | 点子导航 | 头部不动；内容区交叉淡化 | fast | 新内容直接替换 | 同 |
| 换一家公司 | 目录或搜索选中 | 头部文字和内容交叉淡化，布局不动，不整页淡入 | fast | 同 | 同 |
| 视图切换（时间线/看板/表格） | 分段控件 | 交叉淡化，不做布局形变 | fast | 同 | 同 |
| 结构图首次打开、切换集团 | 进入页面、筛选 | 逐层：节点淡入 → 连线描出 → 比例标签淡入 → 下一层节点落位 4px | 节点 fast，连线 build，层间隔 40ms | 再切换立即停止并重算 | 整张直接出现 |
| 结构图增量变化 | 添加或删除股东 | 只有变化的节点和连线生长或淡出；其他节点从旧位置补间到新位置 | build / move | 从当前位置继续 | 直接到位 |
| 结构图缩放、适配视野 | 按钮、筛选后 | scale + translate 补间，锚点为视口中心 | standard / move | 连续点击从当前值继续；用户拖动即取消 | 直接到位 |
| 上传 | 拖入、选择文件 | 进度条宽度跟真实进度 | 线性，每次更新 standard | — | 无过渡 |
| 识别完成 | 文件读完 | 进度条收起；类型标签淡入；汇总框上浮 8px 淡入 | fast；standard | — | 只淡入 |
| 后台处理清单 | 生成合规清单等 | 每步真实完成时对勾从 0.6 放大到 1 | fast / enter | — | 无缩放 |
| 数值变化 | 完成环、进度条、持股条 | 从旧值补间到新值；首次进入页面不播放 | emphasis / move | 从当前值继续 | 直接到位 |
| 标记完成 | 勾选、拖到“已完成” | 数据立即更新；原行淡出 fast；新位置短暂高亮 1s | fast | 不阻塞下一次操作 | 无残影，只高亮 |
| 看板拖动 | 拖卡片 | 卡片跟手，目标列底色加深；松手卡片补间到落点 | standard / move | 拖回原列即取消 | 卡片直接落位 |
| 弹窗 | 打开 / 关闭 | 遮罩淡入；面板上浮 8px 淡入；关闭只淡出 | standard 开 / fast 关 | 关闭中可再次打开 | 只淡入淡出 |
| 菜单、浮层 | 打开 / 关闭 | 从锚点方向 4px + 淡入；关闭只淡出 | fast / instant | 同 | 只淡入淡出 |
| 轻提示 | 操作完成 | 上浮 8px 淡入；6 秒后淡出 | standard / fast | 新提示直接替换旧提示 | 只淡入淡出 |
| 撤销、恢复 | 点「撤销」 | 恢复的行回到原位置，高亮 1s | fast | — | 只高亮 |
| 提示条 | 进入页面 | 随页面一起出现，不在操作过程中插入 | — | — | — |
| 失败 | 操作出错 | 出错的字段描边变 `bad`，文字说明淡入；不抖动 | fast | — | 同 |

## 焦点

- 弹窗打开后焦点进入第一个输入框（没有就进主按钮），Tab 锁在弹窗内；关闭后焦点回到打开它的按钮——除非用户已经在别处打字。
- 打开结构图节点的详情后按 Esc，焦点回到那个节点。
- 列表里删除一行后，焦点移到下一行。

## 验证

每次改动动效都要附：减少动态效果下的截图；关键交互的录屏；动画期间的帧时间（目标 p95 ≤ 20ms，真机测量）；弹窗关闭后焦点所在元素。
