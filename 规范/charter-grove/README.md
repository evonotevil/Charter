Charter 是法务和公司治理人员管理集团公司档案的桌面应用：公司、股权、任职、法定文件、申报截止日，保存在本机和 iCloud。这套设计系统来自 Figma 初稿（参考 Duolingo 的风格），目标是让每天面对截止日和文件的人**轻松一点、安心一点**——界面友好、有鼓励感，但每一个数字和日期都准确、可追溯。

## 设计原则

1. **友好的外壳，严谨的内容。** 页面标题、横幅、空状态、完成时刻可以亲切；表格、字段名、状态、法律术语保持专业准确。
2. **一眼知道情况。** 每个页面先用一条状态横幅回答“现在怎么样”，再给数字卡，再给明细。
3. **下一步永远清楚。** 每家公司都有一张“下一件事”卡片；每条坏消息都带一个可以点的下一步。
4. **立体感 = 可以按。** 只有可操作的东西（按钮、结构图节点）有 4px 立体底边；卡片和信息是平的。
5. **值得庆祝的才庆祝。** 完成一件申报、补齐一家公司的档案、本月全部办完时给一点小奖励；日常浏览快速、安静。
6. **每个结论都有出处。** 字段旁写来源和核对人；识别出的信息能点回原文件。

## 文案

- **标题亲切，细节专业。**
  - 可以亲切的地方：页面大标题（「小步走，根基稳。」「一件一件来。」）、状态横幅（「看起来不错，远澜！」）、卡片标题（「公司背后的人」「样样都在」「接下来」）、空状态和庆祝（「本月全部办完！」）、安心提示（「没网也没关系。」）。
  - 必须专业的地方：字段名、表头、状态胶囊、事项名、机关名、表格编号、错误说明。用法务人员自己的说法：周年申报表、商业登记证、重要控制人、公司秘书。
- 亲切的句子后面一定跟具体信息：「看起来不错，远澜！」→「6 家公司里有 4 家一切就绪，2 件申报需要你留意。」
- 称呼用户「你」，称呼集团用集团简称。不用感叹号堆叠，一句最多一个。
- 按钮动词开头，写清结果：「添加公司」「开始办理」「保留所选版本」。回执用同一个动词：「已标为完成：…」。
- 坏消息不吓人也不轻描淡写：「有 1 件已经逾期。」+ 具体是哪件、过了几天、按钮「马上处理」。
- 日期 `YYYY-MM-DD`；相对时间「还有 28 天」「逾期 3 天」；金额带币种代码 `HKD 10,000`。
- 中文界面不用全大写标签（初稿里的英文大写表头改为普通中文）。

## 视觉基础

**颜色。** 画布 `canvas` 是带绿意的浅灰，卡片 `surface` 纯白。品牌绿 `green`（#58CC02）只用于主按钮、徽标、选中下划线、进度段、开关；绿色**文字**一律用 `green-text`。正文 `ink`，说明 `muted`。

状态色只有三组，都有文字和图标配合：
- 绿（`green-soft` / `green-text`）：正常、已完成。
- 琥珀（`amber-soft` / `amber-text`）：30 天内、办理中、待核实、冲突。
- 红（`red-soft` / `red-text`）：逾期、已过期。

蓝（`blue-soft` / `blue-text`）只用于提示和识别来源；紫（`purple-*`）用于个人。公司徽章底色按**集团**区分，只表达归属。

**对初稿的调整**（为了可读性，其余数值与 Figma 一致）：
| 位置 | 初稿 | 现在 | 原因 |
|---|---|---|---|
| 主按钮文字 | 白 #FFFFFF | `on-green` #1B3608 | 白字在 #58CC02 上只有 2.09:1 |
| 说明文字 | #738078 | `muted` #5F6D66 | 原值在画布上 3.9:1，低于 4.5:1 |
| 绿色文字 | #368A00 | `green-text` #2F7A00 | 原值在浅绿底上 4.04:1 |
| 输入框描边 | #E0E7DD | 悬停时 `line-strong` | 原值 1.26:1，看不清输入框边界 |
| 最小字号 | 9–10px | 11px | 中文在 10px 以下难以辨认 |
| 新增 | — | 红色状态、深色主题 | 初稿没有逾期和深色模式 |

**字体。** 标题用 Nunito（900 / 800），圆润有亲和力；正文用 Inter。中文回落到苹方。`display` 32px 每页一次；`headline` 23px 用于横幅和“下一件事”；`title` 19px 用于卡片标题；正文 13px；说明 12px；标签和胶囊 11px。

**形状。** 描边统一 2px。圆角有层级：胶囊 8、输入框 10、按钮与导航 12、数字卡 16、卡片 20、大徽标 24。**不用阴影**——立体感只来自按钮、徽标和结构图节点底部的深色边（按钮 4px、徽标 6px）；阴影只给弹窗、菜单、轻提示。

**布局。** 侧栏 224px，顶栏 72px，页面边距 32px。区块之间 24px，卡片之间 20px，卡片内边距 24px。公司页面主栏与右栏约 1.65 : 1，右栏放“下一件事”和远期事项。

**交互状态。** 悬停：卡片和行变极浅绿底，次按钮变浅灰底。按下：立体按钮下沉 4px、底边消失，松开回弹。焦点：3px 蓝色外框（`blue-text`），偏移 2px，只在键盘操作时出现。禁用：灰底灰字，保留形状，用 `title` 说明原因。选中：浅绿底 + 浅绿描边 + 绿字。

**长内容。** 公司名最多两行，悬停显示全名；文件名一行截断；一人多职名字只写一次；空字段写灰色「未填」。

## 图标

线性图标，24 网格、2px 描边、圆角端点，与初稿用的 Lucide 一致；实现时可以直接用 `lucide-react`。图标旁一定有文字。

## 标志

鲜绿立体方块里的白色「C」+ Nunito 900 的「Charter」字标（`green-text`）。标志是唯一允许白字压在品牌绿上的地方。
