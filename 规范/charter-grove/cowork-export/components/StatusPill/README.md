# StatusPill

状态胶囊：小圆点（或图标）+ 文字 + 浅色底，圆角 8px。颜色只是加强，去掉颜色也能读懂。

| 色调 | 状态 | 用在 |
|---|---|---|
| 绿 | 正常、已完成、已归档、已核实、存续 | 一切就绪 |
| 琥珀 | 快到期、办理中、待核实、有冲突 | 30 天内要处理，或需要你看一眼 |
| 红 | 逾期、已过期 | 已经过了截止日 |
| 描边 | 待办理、待取得 | 还没开始 |
| 灰 | 不适用、离线 | 不计入统计 |
| 蓝 | 本机、识别结果 | 提示信息，不是状态 |

- 能写具体就写具体：「逾期 3 天」「28 天后到期」。
- 一行只放一个风险胶囊（取最急的）；「已核实」这类附加标记放在后面。
