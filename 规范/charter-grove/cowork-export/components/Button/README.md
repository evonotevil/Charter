# Button

立体按钮：底部 4px 深色边，按下时整块下沉 4px、底边消失，松开时回弹一下。这是整套设计最有辨识度的元素。

- **主按钮**：鲜绿底 `green` + 深绿边 `green-edge`，文字用 `on-green`（深绿）。初稿用白字，对比度只有 2.09:1，读不清，这里改成深绿字（6.4:1）。每个页面最多一个，放在页面标题右侧或卡片底部。
- **次按钮**：白底、2px `line` 描边 + 4px `line` 底边。
- **安静按钮**：无底无边，绿色文字，用于“查看全部”这类链接型操作；按下时只缩到 0.97。
- **危险按钮**：次按钮样式 + 红字，配二次确认弹窗。不用红色实底。
- 尺寸：大 46px（页面级），小 36px（卡片内、表格内）。
- 文案以动词开头、写清结果：「添加公司」「保留所选版本」「开始办理」。
- 禁用：灰底灰字，保留底边形状，并用 `title` 说明原因。处理中：转圈 + 保留文字。
