# HealthBanner

状态横幅：每页最多一个，放在页面标题下方，用一句话回答“现在情况怎么样”。

- 左边是立体大徽标（76px、24px 圆角、6px 底边），中间是标题（Nunito 900 23px）+ 一句说明 + 进度段，右边一个操作。
- 三种色调：一切正常（绿）、需要留意（琥珀）、有逾期（红）。按最急的情况选色调，不混用。
- 标题用亲切口吻（「看起来不错，远澜！」），说明必须给出具体数字和下一步（「2 件申报需要你留意」）。
- 进度段一段代表一家公司，颜色和状态胶囊一致；必须给 `segmentsLabel` 作为读屏文字。
- 状态由好变坏或由坏变好时，徽标轻轻摆动一次（600ms）；首次进入页面不摆。
