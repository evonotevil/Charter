# Sidebar

侧栏：224px 白底，右侧 2px 描边。从上到下：标志、集团切换、主导航、工作区导航、安心提示卡、当前用户。

- **导航项**：48px 高、12px 圆角。选中时浅绿底 + 2px 浅绿描边 + 绿字；悬停时浅灰底。
- **角标**：只放需要处理的数量（逾期为红，30 天内为琥珀），不放总数。
- **集团切换**：灰底卡片，点击切换当前集团；所有页面的统计跟着切换，并在页面里写明范围。
- **安心提示卡**：固定在底部，一句话说明数据保存在哪里（本机和 iCloud），对应初稿里的「A little peace of mind」。
- 窄窗口（小于 1100px）时收起为 72px 图标栏，标志、导航图标保留，文字改为悬停提示。
