# 页面与信息架构

## 导航

| 侧栏 | 页面 | 回答的问题 |
|---|---|---|
| 公司总览 | 状态横幅、四个数字卡、公司表 | 集团整体怎么样？哪家要注意？ |
| 申报日历 | 横幅、范围页签、按月时间线 | 接下来要做什么？哪件逾期了？ |
| 股权结构 | 结构图 | 谁持有谁？ |
| 文件 | 文件表（按公司、按类型） | 文件齐不齐？哪份过期？ |
| 人员与中介 | 人员表、中介表 | 谁在哪家公司任职？哪个中介负责什么？ |
| 工作区 · 设备与同步 | 同步横幅、设备、偏好、冲突 | 这台电脑是不是最新的？ |
| 工作区 · 设置 | 备份与恢复、提醒、规则库 | |

## 页面骨架

每个页面从上到下：面包屑 → 大标题 + 主按钮 → 一行副标题 → 状态横幅（可选）→ 数字卡或概况条 → 页签或筛选 → 内容。范围写在副标题或表格底部：「范围：远澜集团 · 5 个主体」「显示全部 6 家」。

## 公司页面

- 标题区：公司名、事实副标题（法域 · 形式 · 编号）、「导出档案」「编辑公司」。
- 概况条：登记状态、合规、档案完整度、默认中介。
- 页签：概览、人员与持股、文件、申报、变更历史。
- 概览：左栏「基本信息」「公司背后的人」「样样都在」；右栏「下一件事」「接下来」、变更记录说明。

## 尺寸

窗口最小 1100 × 720。小于 1100px 时侧栏收为 72px 图标栏；小于 960px 时公司页面右栏移到主栏下方。
