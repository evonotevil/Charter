# 动效规范

性格：**有弹性、会鼓励，但从不拖慢你。** 日常操作的反馈快而短；只有完成一件事时才多给一点点。

## 时长与曲线

| 名称 | 时长 | 用途 |
|---|---|---|
| press | 80ms | 按下下沉 |
| fast | 120ms | 悬停、颜色变化、淡出、内容交叉淡化 |
| standard | 200ms | 页签下划线、开关圆点、选中、弹窗关闭前的淡出 |
| emphasis | 320ms | 弹出类：对勾、轻提示、弹窗、进度回弹 |
| celebrate | 700ms | 彩点散开 |

| 曲线 | 值 | 用途 |
|---|---|---|
| enter | `cubic-bezier(.2,.8,.2,1)` | 普通出现 |
| exit | `cubic-bezier(.4,0,1,1)` | 消失 |
| move | `cubic-bezier(.3,0,.2,1)` | 位置移动（下划线、视野） |
| bounce | `cubic-bezier(.34,1.56,.64,1)` | 回弹：按钮松开、对勾、开关、进度、弹窗弹入 |

## 规则

1. **快的反馈不打折。** 按下、悬停、选中都在 200ms 以内完成，回弹只用于松开和弹出，不用于移动大块内容。
2. **庆祝只给真正完成的事。** 只在用户亲手完成一件事时触发：标为完成、档案补齐 100%、本月全部办完、第一次导入完成。打开页面、刷新数据从不触发。同一件事只庆祝一次。
3. **不排队、可打断。** 新的操作直接接管；庆祝动画在独立图层播放，不挡住下一次点击。
4. **数据先变。** 标为完成时，数据、计数、横幅立即更新，动画只是附加。
5. **不移动正要点的东西。** 卡片悬停不上浮；插入的内容不把按钮推走；提示条只在进入页面时出现。
6. **只动 transform 和 opacity**（进度条宽度除外）。
7. **减少动态效果**：去掉下沉、回弹、摆动、彩点、生长和依次出现；按钮按下改为颜色加深，弹窗和轻提示只淡入 120ms，对勾直接出现。

## 场景

| 场景 | 触发 | 动画 | 时长 / 曲线 | 减少动态效果 |
|---|---|---|---|---|
| 立体按钮按下 | pointerdown | 下沉 4px，底边归零 | press / enter | 只加深颜色 |
| 立体按钮松开 | pointerup | 回弹到原位，略过冲 1px | standard / bounce | 无 |
| 导航、行悬停 | 指针进入 | 底色、描边颜色 | fast | 同 |
| 页签切换 | 点击、方向键 | 下划线滑到新页签；内容交叉淡化 | standard / move；fast | 直接到位 |
| 列表 / 卡片切换 | 点击 | 内容交叉淡化 | fast | 同 |
| 开关 | 点击 | 圆点滑动带回弹，底色变绿 | standard / bounce | 直接到位 |
| 单选卡片 | 点击 | 底色变浅绿，圆点弹出 | fast；standard / bounce | 无弹出 |
| 状态横幅 | 状态变化 | 徽标摆动一次；进度段只重填变化的一段 | 600ms / bounce | 无 |
| 进度段 | 首次进入页面 | 依次填满，间隔 90ms | emphasis / bounce | 直接填满 |
| 档案完整度条 | 进入、数值变化 | 从旧值回弹到新值 | emphasis / bounce | 直接到位 |
| 结构图生长 | 首次打开、切换集团 | 顶层节点弹入 → 连线描出 → 比例胶囊弹出 → 下一层弹入，层间隔 440ms | 节点 standard / bounce，连线 360ms / move | 整张直接出现 |
| 结构图节点按下 | 点击 | 下沉 2px | press | 无 |
| 结构图视野 | 筛选后、缩放按钮 | 缩放与平移补间 | standard / move | 直接到位 |
| **标为完成** | 点完成圆圈 | 圆圈填绿 → 对勾弹出 → 10 个彩点散开 → 事项名划线；同时出现带「撤销」的轻提示 | 120ms；emphasis / bounce；celebrate | 直接显示对勾，无彩点 |
| **本月全部办完 / 档案补齐** | 最后一件完成时 | 原位置换成庆祝卡片：徽标弹入 + 彩点 | 520ms / bounce；celebrate | 静态徽标和文字 |
| 上传 | 选择或拖入文件 | 进度条按真实进度推进 | 线性 | 无过渡 |
| 识别完成 | 文件读完 | 汇总框上浮 8px 淡入 | standard / enter | 只淡入 |
| 处理步骤 | 后台任务 | 每步真实完成时对勾弹出 | emphasis / bounce | 直接显示 |
| 轻提示 | 操作完成 | 从下方 16px 弹入；6 秒后淡出 | emphasis / bounce；fast | 只淡入淡出 |
| 弹窗 | 打开 / 关闭 | 上浮 12px + 0.97 缩放弹入；关闭只淡出 | emphasis / bounce；fast | 只淡入淡出 |
| 撤销 | 点「撤销」 | 事项恢复原状，行高亮 1 秒 | fast | 只高亮 |
| 错误 | 校验失败 | 描边变红，说明淡入；不抖动 | fast | 同 |

## 焦点

- 弹窗打开后焦点进第一个输入框或主按钮，Tab 锁在弹窗内；关闭后回到打开它的按钮。
- 标为完成后焦点留在同一行，按「撤销」后也回到这一行。
