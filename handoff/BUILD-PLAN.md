# Charter 双端版：一次做全的功能清单

设计以 DESIGN.md 和 visual-spec.html 为准。

## 已定决策
| 项目 | 决定 |
|---|---|
| 技术栈 | Tauri 2 + React + TypeScript，一套代码出 Mac / Windows |
| 已有代码 | 保留 `desktop/src/domain`（日期、到期、规则、股权、识别、结构图布局、文件夹读写），界面全部按视觉规范重写 |
| 数据 | 用户自选云盘文件夹；每类数据一个 JSON 文件（`data/companies.json` 等），标准 JSON，不再兼容 Swift 格式；原子写入 |
| OCR | 系统自带：Mac Vision，Windows Windows.Media.Ocr；PDF 先读文字层，读不到再 OCR |
| 日历 | 在数据文件夹生成 `.ics`，用户自行订阅 |
| 发送 | 交办、请补发、催办只**复制文字**，用户自己粘贴发送，再点“确认已发送” |
| 合规模块 | 默认关闭，设置里打开 |
| 打包 | 只出 Mac 安装包（在 Mac 上 `npm run tauri build`，见 desktop/README.md）；Windows 代码保留，暂不打包 |
| 签名与自动更新 | 暂不做 |
| 示例数据 | 沿用远澜集团；远澜控股（香港）、Yuanlan International 材料齐全，Harbor Crest Investments 够 KYC |

## 数据文件夹
```
<所选文件夹>/
  data/ companies people holdings appointments parties groups documents requests obligations changes settings .json
  templates.json          模板库（法域、文件类型、档案清单、规则、用途）
  files/<公司或人员>/<名称_类型_签发日>.pdf
  packets/                 生成的文件包
  snapshots/<时间>/        每日与危险操作前的快照
  group-icons/<集团ID>.png
  .undo/                   撤销时暂存的文件
  Charter 合规日历.ics
```
按设备区分的偏好（窗口、缩放、上次用途、导入草稿）存在本机，不放进同步盘。

## 功能（全部纳入第一版）
**基础**
- 首次使用：选择数据文件夹 → 欢迎页（拖入文件 / 新建集团 / 载入示例数据）
- 侧栏：集团切换、五个页面、同步状态、设置入口
- 命令面板（Ctrl/⌘ K）：搜索公司、人员、动作，支持“远澜 开户”这类一句话
- 撤销 / 重做，所有批量和破坏性操作都附提示条“撤销”
- 浅色 / 深色，快捷键全套（见 DESIGN.md）

**总览**：主指标、按用途的准备度、接下来 30 天、在等回件

**公司**
- 列表 + 详情：身份、关键信息、档案清单（标记原因、备注、单行归档、自定义清单）、任职与股东、穿透结果、变更记录、历史版本、合规事项（模块开启时）
- 矩阵：集团 × 档案类别
- 股权结构图：拖动布局、缩放、链条高亮、向上穿透、核对股东、年份回放、详情栏
- 编辑公司（含从注册证书预填）、新建 / 编辑集团（含图标）、成员管理、添加上下级、持股链条查询

**文件**：筛选、列表 / 缩略图、多选、导出 ZIP、文件详情（预览、改类型 / 归属 / 日期、归档新版）

**导入**：拖入文件或文件夹 → 逐份识别 → 确认（低把握标琥珀）→ 新公司草稿 → 归档 → 完成页；可保存草稿稍后继续

**变更向导**：董事、股东、地址、名称、状态变更；证明文件；预览影响后确认

**文件包**：按用途挑选、缺件提示、生成 ZIP（含目录 PDF / Excel）、复制发送说明；导出全部档案

**补发与等回件**：请补发（复制文字并记录）、跟进日提醒、催办、改由他人、取消

**人员 / 负责方**：详情、编辑、合并重复人员、删除校验；负责方的等回件、负责事项、公司

**合规（模块开启时）**：事项计算、交办状态流、规则核对、合规日历（筛选、批量交办、导出 PDF / CSV）、`.ics`

**提醒**：系统通知（到期前 N 天、跟进日），只由“主电脑”发送

**设置**：数据与同步、提醒、档案清单、文件包用途、合规规则、备份与配置（快照恢复、配置导入导出、示例数据、清空）、功能模块

## 开发顺序（每步都能在浏览器预览里看到）
1. 数据层改造：标准 JSON 格式、新文件夹结构、测试
2. 外壳：侧栏、路由、弹窗框架、提示条、设置窗
3. 公司 → 文件 → 导入 → 总览
4. 人员、负责方、补发
5. 矩阵、结构图、变更向导、文件包
6. 合规、日历、提醒、设置其余各页
7. Tauri 原生部分（文件、监听、OCR、通知）与 Linux 构建
8. 逐页对照视觉规范截图验收

## 进度
1–8 步已完成：浏览器预览逐页截图核对过，Linux 原生版已编译并在虚拟显示器上跑通示例数据。
未在真机验证：Mac 的系统 OCR（Vision）与同步状态、系统通知。
