Charter 视觉规范

集团公司档案管家的界面语言。数值与 Swift 版 DesignSystem / Kit 一致，桌面版（Tauri + React）照此实现。

原则

黑白骨架

灰底画布、白色承载面、墨色文字。结构靠留白和细线，不靠边框和阴影。

一个柠檬绿

只用在首页主指标、拖放区、"已归档 / 完整"和股权图的控制链高亮。

颜色有语义

琥珀 = 需要处理；红 = 已过期 / 逾期。状态同时用图形和文字表达。

确认才写入

导入、变更、配置导入在最后确认前不改档案；批量操作都能撤销。

颜色

所有色值都是 token。切换右上角的主题可以看到深色值；柠檬绿在两种主题里不变。

中性

强调与语义

字体

系统字体，不加载网络字体。Mac：SF / 苹方；Windows：Segoe UI Variable / 微软雅黑 UI。注册编号、日期、比例用等宽数字。
