# Charter 设计规范

本规范给做 Mac + Windows 迁移的 agent 用。以 Swift 版（`Charter/Views/DesignSystem.swift`、`Kit.swift`、`Components.swift`）为准。数值在 `tokens.json`，可直接用的 CSS 在 `charter.css`。两份文件与 Swift 版逐项对齐，有冲突时以 Swift 版为准。

## 1. 产品定位与语气

- Charter 是集团公司档案管家：管理公司档案、股权结构、文件到期、补发请求和合规申报。用户是法务、公司秘书和财务。
- 界面全中文。公司名、人名保留原文；中文句子里夹英文名时，两侧各补一个空格（`latinPad`）。
- 文案写成指令或事实，用户读完就知道下一步做什么。不道歉，不写营销腔。按钮写动作，结果提示沿用同一个动词：按钮“归档新版”，提示“已归档”。
- 出错说明三件事：发生了什么、数据有没有受影响、怎么办。例如“归档失败，档案没有改动：……”。
- 空状态给出下一步动作，例如“选择公司”和“新建公司”。
- 日期显示为“2026年10月13日”或“10月13日”。表格里的日期用等宽字体，写成 `yyyy-MM-dd`。百分比用 `percentLabel`：整数不带小数，其余最多两位。

## 2. 视觉基调

- **黑白骨架，一个柠檬绿强调。** 页面主体只有灰底 `canvas`、白色 `surface` 卡片和墨色文字。柠檬绿 `lime #D9F46B` 只在三类地方出现：
  1. 首页主指标卡和拖放区
  2. 已归档或完整的状态
  3. 股权图里高亮的控制链
- **状态色有语义：**
  - 琥珀（amber）表示需要处理：即将到期、需更新、待核对。
  - 红（danger）只表示已过期或已逾期。
  - 不用蓝色和绿色表示“成功”。“有效”用柠檬绿浅底 `limeSoft` 配深橄榄字 `limeText`。
- **颜色不单独表达含义。** 状态同时用图形和文字表达：矩阵格子有图标，胶囊有文字，股东核对的圆环旁边有标签。
- **选中态用墨色实底**（`selection`），文字为白色。暗色模式下选中底色是 `#4A4A52`。
- **深色模式**按 `prefers-color-scheme` 切换。`:root[data-theme]` 可以强制指定模式。柠檬绿在两种模式下保持不变。

  - 输入框：12
  - 列表行悬停底色：10
  - 卡片：20
  - 大弹窗：26
  - 拖放区：24

- 侧栏宽 250。

- 股权图节点：公司 280×70，圆角 22；人员 170×56，胶囊形。

## 5. 动效与交互流畅度

### 5.1 基本原则

1. **快于思考**：任何操作 100ms 内要有看得见的反馈。动效是在说明“发生了什么”，不是装饰。
2. **只回应操作**：动效只跟着用户的动作出现。不做自动播放、呼吸灯、进场时逐块上浮。
3. **先显示，后保存**：编辑、勾选、删除都立即反映在界面上，写盘在后台进行。失败时回滚，并用提示条说明。
4. **进来慢一点，出去快一点**：出现用 standard 或 panel 档，消失用 fast 档。
5. **一个变化只动一处**：同一时刻不让多个区域同时位移。

### 5.2 时长与曲线（`tokens.json` → CSS 变量）

| 变量 | 时长 | 用于 |
|---|---|---|
| `--instant` | 80ms | 按下反馈、消失 |
| `--fast` | 120ms | 悬停、勾选、颜色变化、菜单收起 |
| `--standard` | 200ms | 选中滑动、展开收起、开关、分段控件、整页淡入 |
| `--panel` | 280ms | 弹窗、设置浮层、信息卡、提示条出现 |
| `--long` | 900ms | 只给归档印章这类“完成时刻”，一屏最多一个 |

- **曲线**：
  - `--ease: cubic-bezier(.2,.8,.2,1)`：出现、移动用，起步快、收尾轻。
  - `--ease-out: cubic-bezier(.4,0,1,1)`：消失用。
- **禁止**：在组件里直接写 `.2s`、`ease`、`linear`，必须用上面这些变量。只有加载转圈可以用 `linear`。

### 5.3 响应速度

| 情况 | 要求 |
|---|---|
| 点击、按键 | 100ms 内有反馈（按下态、选中态、光标） |
| 本地操作（改字段、勾选、删除、切换页面） | 立即完成，不显示加载 |
| 读文件、识别证书、打包导出 | 300ms 内显示进度（转圈或进度条），并写明在做什么，如“正在识别…” |
| 超过 3 秒 | 显示阶段文字或百分比，并允许取消 |
| 失败 | 恢复原状，提示条写清原因和下一步，不弹对话框 |

骨架屏只用于首次读取数据文件夹，其余场景不用。

### 5.4 组件动效

**按钮**
- 悬停：底色变化，用 fast。
- 按下：缩到 0.97，用 instant；松开时回弹，用 fast。
- 禁用：没有任何动效。

**列表行、导航项、选中态**
- 悬停底色用 fast。
- 选中切换：底色直接到位。分段控件和集团切换条用“底色滑动”，standard。

**开关、勾选**
- 圆点滑动和底色同步，standard。
- 勾号用 fast 淡入。

**菜单、下拉、气泡**
- 出现：从锚点方向位移 4px，加透明度和 0.98 缩放，fast。
- 消失：只做透明度变化，instant。

**弹窗、设置浮层**
- 出现：背景遮罩淡入 standard；面板上浮 12px 加 0.985 缩放，panel。
- 消失：遮罩和面板一起淡出，fast。
- 打开后焦点落到第一个输入框或主按钮；Esc 关闭。

**信息卡、右侧详情**
- 首次出现：从右侧 12px 淡入，panel。
- 切换选中对象时不重新滑入，只把内容淡入一次，standard。

**提示条（toast）**
- 出现：从底部 16px 升起，panel。
- 停留 4 秒，悬停时暂停计时；带“撤销”的停留 6 秒。
- 消失：下沉 8px 加淡出，fast。
- 新的一条直接替换旧的，不叠加。

**就地编辑**
- 悬停显示浅底，fast。
- 进入编辑：变成白底加 1.5px 黑色描边，fast，光标定位到点击处。
- 回车或失焦保存，Esc 放弃；保存后描边立即消失。

**列表增删**
- 新增的一行：浅色底高亮 1 秒，再用 standard 淡回。不做展开动画。
- 删除：这一行淡出，fast，下面的行直接补位。撤销恢复时按“新增”处理。

**拖放**
- 文件拖进可放置区域：边框变成 2px 黑色，并显示“松开即可归档到…”，fast。
- 松手：识别过程中显示转圈；完成后用提示条反馈。区域本身不做动画。

**结构图**
- 缩放、平移跟手，不加缓动。用按钮缩放时用 standard。
- 选中节点：节点描边和持股链路高亮同时出现，fast；若节点不在视野里，平滑滚到可见，standard。
- 切换集团、打开历史：整图淡入一次，standard。时间轴回放每一步之间停 1.4 秒，节点位置变化用 panel。
- 拖动节点：跟手；松手时直接落位，不回弹。

**归档完成印章**
- 圆环 0.9 秒画出，圆点 0.3 秒弹出，只在这一处使用 long。

### 5.5 减少动态效果

系统打开“减少动态效果”时：
- 所有位移和缩放取消，元素直接到位。
- 透明度变化保留，统一用 fast。
- 印章直接显示完成状态，结构图滚动改为直接跳转。
- 加载转圈保留。

### 5.6 焦点与键盘

- 用键盘移动焦点时，显示 2px 黑色焦点环，外偏移 2px，直接出现、不做动画。鼠标点击不显示焦点环。
- 上下键切换列表时，选中项跟随滚动，保持在可见范围内。

## 6. 组件（与 Swift Kit 对应）

**按钮 `PillButton`**：

| 类型 | 外观 | 用途 |
|---|---|---|
| primary | 墨底白字 | 每屏最多一个，例如“准备文件包…”“归档全部” |
| secondary | 白底，悬停变 band | 一般操作 |
| accent | 柠檬绿底 | “复制公司资料摘要”“复制发送说明” |
| quiet | 透明，悬停变 band | 行内和工具栏 |
| danger | 红底白字 | 仅用于不可撤销的操作，例如“清空…”“全部替换” |

- 按钮可以带图标。
- 按钮内带下拉菜单时，用 `ActionMenu`，菜单箭头为 chevron.down。

**胶囊 `Pill`**：

| 种类 | 用途 |
|---|---|
| valid | 柠檬绿浅底 |
| warn | 琥珀浅底 |
| bad | 红浅底 |
| strong | 墨底，用于公司状态 |
| outline | 虚线或描边，用于未取得、未归档 |
| neutral | band 底 |
| lime | 柠檬绿实底 |

**档案状态（ArchiveState）的映射：**

| 状态 | 胶囊 | 图标 | 矩阵格子 |
|---|---|---|---|
| 有效 | valid | checkmark.circle.fill | 绿底 ✓ |
| 日期待核对 | warn | checkmark.circle.fill | 绿底 ✓ |
| 即将到期 N 天 | warn | clock.badge.exclamationmark | 琥珀底时钟 |
| 需要更新 | warn | arrow.triangle.2.circlepath | 琥珀底 |
| 已过期 N 天 | bad | xmark.octagon.fill | 红浅底 ! |
| 未归档 | outline | circle.dashed | band 空格 |
| 标记：未取得 / 受限 | outline | questionmark.circle / lock | band |
| 标记：待核实 | warn | questionmark.diamond | 琥珀 |
| 标记：外部保管 / 不适用 | neutral | building.columns / minus | band / “—” |

**其他组件：**

- **表单**：`FormGroup` 是白卡片带小标题；放在设置画布上时为 canvas 版。`FieldRow` 左侧是标签列，下方有灰色 hint，错误时显示红色 error。
- **输入控件**：`SelectField`（自绘弹出）、`DateField`（可直接键入 yyyy-MM-dd，带日历面板；有 relativeTo 时可选“签发后 N 个月”）、`TextField`、`ListField`（以逗号分隔）、`Checkbox`、`Switch`（开为墨色或柠檬绿）、`RadioGroup`、`Segmented`（胶囊分段，选中为墨底）。
- **弹窗 `SheetScaffold`**：
  - 顶部：标题和副标题
  - 中间：内容可滚动
  - 底栏：左侧放次要操作（删除、上一步、补发），右侧放取消和主按钮
  - Esc 关闭，Enter 触发主按钮
  - 正在写入时禁止关闭
  - 常用宽度：420、520、560、600、640、720、960、1000、1240
- **确认框 `ConfirmSheet`**：用于删除和覆盖。可以附 details 列出将受影响的内容。
- **提示条 `Toast`**：显示在底部居中，墨色胶囊，可带“撤销”。所有批量或破坏性操作都要提供撤销，同时支持 ⌘/Ctrl+Z。
- **徽标**：
  - `JurisdictionBadge`：法域代码方块，圆角为边长的 30%，band 底；高亮时柠檬绿底。
  - `Avatar`：首字圆形。名义股东用虚线圆圈表示。
  - `GroupIcon`：集团图标，存为 256px PNG，圆角为边长的 28%；没有图标时显示首字。
- **进度**：`ProgressCapsule` 和 `ProgressTrack` 都是柠檬绿的细进度条，高 5–6。识别和导出过程用墨色进度条。
- **空状态 `EmptyStateView`**：圆形图标、标题、一句话说明、一个动作按钮。
- **骨架屏 `Skeleton`**：加载时使用，不用转圈占满屏幕。
- **图标**：沿用 SF Symbols 名称，桌面端通过 lucide-react 映射（见 `desktop/src/ui/Icon.tsx`）。新图标必须加进这张映射表，否则会显示成空心圆。

## 7. 布局与页面

**窗口与侧栏：**

- 窗口分为左侧栏和右侧主区，主区底色为 canvas。
- 侧栏从上到下依次为：
  1. 集团切换器（GroupSwitcher）
  2. 五个页面：总览、公司（数字角标为需处理数）、文件、人员、负责方
  3. 底部是同步状态和齿轮图标（打开设置）
- 设置是整窗覆盖层，左侧有分组导航：
  - 常规：数据与同步、提醒
  - 模板库：档案清单、文件包用途、合规规则（打开合规模块后才显示）
  - 高级：备份与配置、功能模块

**各页面：**

1. **总览**。从上到下依次为：
   1. 问候语和 ⌘K 搜索框
   2. 柠檬绿主指标卡：“N 项需处理”和分项说明；有个人文件或股东不完整时，给出下划线链接；右侧是“先处理第一项”
   3. 随时能出哪些材料：按用途分行，可展开查看每家公司缺什么，并可请补发
   4. 接下来 30 天：按已逾期、本周、30 天内、需更新/待核对分组，每组最多 6 条
   5. 在等回件
2. **公司**，页头用分段控件在列表、矩阵、结构之间切换：
   - **列表**：左栏按集团分组，按持股层级缩进；有问题的公司右侧显示红点或琥珀点。右侧是详情：顶部身份信息和操作 → 关键信息条（注册编号、成立日期、地址、档案 x/y）→ 分段（档案、变更记录、历史版本、合规事项）。档案清单表格的列为：条目、状态、签发、到期、操作。宽屏时右侧显示任职人员、股东和穿透结果。新公司还没有文件时，显示大拖放区、清单预览和下一步。
   - **矩阵**：每个集团一张卡片。行是公司，最多 9 列档案类别，单元格见上面的状态表。
   - **结构**：点阵画布上的股权图。可切换向下展开或向上穿透；可开关“核对股东”，在节点外加状态圆环并给出待补清单。底部有年份回放条。点选节点后，右侧打开 340 宽的详情栏。
3. **文件**：
   - 范围：公司与人员 / 公司 / 个人。状态：全部、即将到期（时间范围 30/60/90/183 天）、需处理、最近添加。可在列表和缩略图之间切换。
   - 按归属分组显示。支持多选（⌘/Ctrl 点按和 ⇧ 连选），选中后底部浮出操作条：打开、显示文件位置、移除、导出 ZIP。
   - 有未完成的导入时，顶部显示“继续”横幅。
4. **人员 / 负责方**：左栏列表，右侧为单张承载面详情。区块之间用细线分隔，没有内容的区块不出现，最后用一句话说明缺了哪些。
5. **合规日历**（仅在合规模块打开时可用）：
   - 时间范围分段，可按负责方、法域、集团、状态筛选。
   - 筛出的事项可以一并交办或导出 PDF/CSV。
   - 显示 12 个月的分布条。月份标题吸顶。

**导入流程**（拖入文件或点“上传材料”时开始）：

1. 逐份识别：读取 PDF 文字，读不到时用系统 OCR。
2. 列表显示识别结果。把握低的行用琥珀描边，必须确认后才能归档。
3. 可以新建公司草稿。
4. 关闭窗口时自动保存草稿，之后可继续。
5. 归档完成后显示“已归档”页：印章动画，以及按用途列出的准备度。

## 8. 交互约定

**快捷键**（Mac 用 ⌘，Windows 用 Ctrl）：

| 快捷键 | 功能 |
|---|---|
| K | 命令面板 |
| , | 设置 |
| 1–5 | 切换页面 |
| N | 新建当前页的对象 |
| ⇧N | 新建公司 |
| I | 上传材料 |
| ⇧E | 导出 |
| L | 查询持股链条 |
| Z / ⇧Z / Y | 撤销 / 重做 / 重做（Y 仅 Windows） |
| F | 当前页搜索 |
| A | 全选（文件页） |
| ↑ ↓ | 在列表中切换 |
| Esc | 关闭 |

**其他约定：**

- 右键菜单与行尾的“…”菜单内容一致。
- 拖放：整个窗口都能拖入文件。拖到某家公司的详情区、集团卡片或单个档案行上时，直接归入对应位置；目标区域会盖一层柠檬绿并标出虚线框。
- 键盘焦点用 3px 柠檬绿外框。行的焦点用浅底，不用系统默认的焦点框。
- 写入数据的操作只在用户最后确认时执行。导入、变更向导、配置导入在确认前都不改动档案。
- 批量写入前先保存本地快照。

## 9. 双平台差异

- 文案要中性：用“这台电脑”，不用“这台 Mac”；在 Windows 上写“在资源管理器中显示”，在 Mac 上写“在访达中显示”。
- 同步盘不限 iCloud，也支持 OneDrive 等，界面里统称“同步盘”。
- 窗口标题栏：
  - Mac：标题栏透明，顶部留 28px 拖拽区
  - Windows：用原生标题栏，顶部留 6px
- 日历功能是在数据文件夹里生成 `.ics` 文件供订阅，不直接写入系统日历。
