Charter 5.1.0：只有一种全新外观，Windows 能稳定打开，结构图重做，人员可以存个人文件。

## 下载与安装

- **Mac（Apple 芯片，M1 及以后）**：`Charter-5.1.0-Mac-arm64.dmg`。打开后把 Charter 拖进「应用程序」。
- **Mac（Intel）**：`Charter-5.1.0-Mac-x64.dmg`。
- **Windows 10/11**：推荐 `Charter-5.1.0-Windows-Setup.exe`；也可以使用免安装版 `Charter-5.1.0-Windows-x64.zip`。
- `SHA256SUMS.txt` 用于核对下载文件。

应用没有正式签名：Mac 第一次打开时在访达里右键 →「打开」；Windows SmartScreen 提示时选「更多信息」→「仍要运行」。

## 新内容

- **Windows 不再白屏**：界面先画出来再读数据；出错时显示原因和「重新打开」「更换数据文件夹」；文件被占用时自动重试写入；日志写在 `%APPDATA%\Charter\logs\main.log`（Mac：`~/Library/Logs/Charter/main.log`）。打包时自动做一次启动自检。
- **新图标**：Mac 图标铺满，由系统裁成圆角，不再有浅色底板；Windows 保留圆角。
- **只有一种外观**：去掉柔和和经典，全部页面按设计系统重做——侧栏、公司总览（状态横幅、数字卡、公司表）、公司页（页签 + 右侧「下一件事」）、申报日历（打勾完成）、文件、人员与中介；设置和「设备与同步」成为页面。
- **集团色只用在徽章和小圆点上**，卡片和节点一律白底。
- **股权结构重做**：分层排布，交叉更少，共用的公司只画一次；实线为已核实，虚线为待核实，琥珀色为代持；点选节点高亮整条控制链并在右侧出摘要，双击打开；搜索并居中、折叠、以它为中心、方向键切换、导出 PNG/PDF；另有缩进列表视图。首次打开和切换集团时按层生长。
- **设置的关闭按钮点不动**：原因是标题行被当成了窗口拖动区。设置改成页面，拖动区只留窗口顶部一条。
- **个人文件**：人员页可以上传、拖入、预览个人文件（护照、身份证件、住址证明、简历、董事同意书、委任书、辞任书、个人声明、背景调查），显示必备文件是否齐全，到期前提醒；文件可以同时关联一家公司，会出现在该公司的「人员与持股」页签里。

## 数据

数据文件夹格式不变，5.0 的数据直接打开。模板库会自动补上新的个人文件类型，「地址证明」改名为「住址证明」。

## 验证范围

GitHub Actions 会在原生 macOS 和 Windows 构建环境运行单元测试与生产构建。macOS 包会校验版本、架构、ad-hoc 签名、应用资源和 DMG/ZIP 完整性；Windows 会静默安装、启动应用并检查窗口。
