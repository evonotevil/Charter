Charter 5.4.0：申报事项自动同步到系统日历；源文件丢失时明确提示并可重新定位；修复面板里的下拉选不中；窄窗口日历详情改为抽屉；无障碍语义修复。

## 下载与安装

- **Mac（Apple 芯片）**：`Charter-5.4.0-Mac-Apple芯片.dmg`。
- **Windows 10/11**：`Charter-5.4.0-Windows-安装版.exe`。安装前请先退出 Charter。

## 新功能：自动同步到系统日历

- 设置 → 提醒 →“自动同步到系统日历”。Mac 写入 Apple 日历（第一次会请求日历权限），Windows 写入桌面版 Outlook。
- 同步内容：400 天内未完成的申报事项和现行文件的到期日。新增、改期、完成、删除都会自动更新；完成或删除的事项会从日历里删掉。
- 只写入名为“Charter”的那本日历（日历名称可在设置里改），不会改动其他日历。
- 只在“由这台电脑发通知”的电脑上运行，多台电脑共用数据文件夹时不会产生重复事件。
- Windows 新版 Outlook 和自带“日历”应用不允许其他程序写入，这些电脑继续用 .ics 订阅文件。

## 修正

- **待核实 → 关联依据并核实**：在“依据”下拉里选文件时整个面板会关闭、选择不生效（Mac 和 Windows 都会）。现在面板里的下拉可以正常选择；Esc 只关最上面一层。
- **源文件不可用**：启动、数据变化和回到窗口时检查每份现行文件是否在数据文件夹里。找不到的文件统一显示“源文件不可用”，计入“需处理”，不再显示“已归档”；详情里直接提供“重新定位…”（选回文件现在的位置，复制进数据文件夹，原件不动）和“归档新版…”。
- **打开失败不再静默**：打不开时提示原因和下一步。
- **窄窗口日历**：窗口较窄（单栏）时，点击事项从右侧打开详情抽屉并聚焦标题，Esc 关闭后回到原来的行。
- **无障碍**：日历行不再是“按钮里套按钮”，选中状态改用 aria-current；文件表、公司表的表头补上读屏文字；侧栏两个导航区域分别命名。axe 扫描日历、文件、总览三页均为 0 项问题。
- **写入更稳**：保存时临时文件被同步盘或杀毒软件移走，会自动重写重试。

- **长 PDF**：预览顶部显示“共 N 页 · 第 x 页”和“打开原件”；部分页面无法显示时会注明。

# 5.3.3

## 5.3.3 修正

- **菜单名**：Mac 菜单栏和“关于”显示“Charter”（原来是 charter-desktop），菜单改为中文；原有设置（包括数据文件夹位置）不受影响。
- **新建公司的股东、董事**：点进输入框就列出已有的人（股东还列出公司），打字过滤，忽略大小写和空格、匹配别名；方向键选择、回车确认；没有匹配时最后一行是“新建”。

## 5.3.2 修正

- **长期有效的证件**：到期日的提示按文件类型说明。到期日写在证件上的类型（护照、身份证件等）可以勾选“文件上写明长期有效 / 没有到期日”，勾选后显示“长期”、不算需处理；不勾选又不填，仍算“未填日期”。本身长期有效的类型提示“无需填写”。

# 5.3.1

## 5.3.1 修正

- **“需处理”只有一个口径**：已过期、快到期、需更新、未填日期都算；文件页的指标卡、标签、分组徽标、行状态和侧栏角标都按同一结果计数，公司和个人文件都包含。页头不再在日期未知时说“都在有效期内”，改为列出“n 份已过期、n 份日期待补”。
- **总览完整度拆开说**：还有公司未配置时，主数字是“已配置 x/y 家”，已配置项的完整度放在小字；全部配置完才显示齐全度。
- **材料范围弹窗**：每个条目只有一个“改为”下拉（默认“本次不改”），并显示“现在”的范围；可以勾选多个条目一次设定；底部显示“对象数 × 条目数，共改几处”。取消不写入任何改动。
- **集团颜色所见即所得**：不再把颜色替换成别的预设色。自定义时选红、橙、黄、绿会被拒绝并保留原色；已有的红绿集团保持原色，在设置 → 集团里提示建议更换。
- **不能删除的人员**：“删除”按钮显示为禁用，悬停和读屏可以读到原因。
- **人员文件计数**：写成“已归档 6 份 · 5 类”；同类第二份也显示自己的状态。
- **完整性审阅**：左边是文件状态（缺件 / 未归档），右边是带边框的“保管 待确认”，不再出现两个“待确认”。
- **股权结构**：选中节点、右侧摘要打开后，画布自动平移让节点和直接关系留在可见区域，不改缩放。
- **深色模式**：已选分段使用高对比底色和文字；手动选“深色”时输入框占位文字也达到 4.5:1。

# 5.3.0

## 材料范围

- 公司和人员的每个材料条目都可以标为 **我负责 / 中介保管 / 不在我的范围 / 不适用 / 待确认**。可以批量设置、存成方案一键套用，应用前预览改动，之后可以撤销。
- **完整度只算“我负责”的条目里有多少已归档。** 没设置过范围的公司显示“未配置材料范围”，不再把 0/0 算成 100%。
- 法域清单只作为“常见要求”出现在完整性审阅里，不再推断你缺件。
- 设置 → 材料范围：查看哪些公司、人员还没配置，管理保存的方案。

## 两种视图

- **已有材料**（默认）：只显示已经归档的文件。
- **完整性审阅**：按缺件、需处理、待确认、中介保管、已齐分组显示缺口。
- 人员的“必备”材料跟随范围设置，不再全局写死。

## 待整理

- 拖进窗口或点“加入待整理”的文件先进入 **文件 → 待整理**，不直接进正式档案。
- 在本机识别文字中的姓名和公司名，按内容哈希去重，给出分类建议和置信度。
- 批量归到公司、人员、任职证据，或标为无关移到废纸篓；可以撤销。

## 证据链

- 一份文件可以同时关联多家公司、多个人、具体任职和持股，记录证据类型、页码和来源路径。合并 KYC、董事会文件这类材料不用再复制多份。
- 公司页和人员页显示“其他文件里的证据”。

## 删除与废纸篓

- 删除前列出影响范围：Charter 里的副本、你原来的文件（不受影响）、旧版本、关联记录。
- 删除的文件进入 **文件 → 废纸篓**，30 天内可以恢复，之后自动清除。

## 界面修正

- **人员文件不再被折叠**：同类文件（例如两家公司的董事同意书）每份单独一行，不再只显示最新那份。
- **总览不再报喜不报忧**：只有在没有逾期、过期、待核实、缺件和未配置时才显示“没有待处理事项”；否则按紧急程度列出要处理的事。申报日历和侧栏的成功提示改为一行灰字。
- **文件表更好扫读**：第二行只显示类型；点“文件 / 签发 / 到期 / 状态”表头可以排序。
- **集团颜色不再用红、橙、黄、绿**，这几种只表示状态；已有的红色、绿色集团自动显示为相近的中性色，可以在设置里改。
- **人员页更安静**：“不能删除”的原因点了删除才显示；合并只保留一个“合并到…”入口。
- **可访问性**：输入框占位文字对比度达到 4.5:1 以上；文件表每个复选框都读出文件名；最小字号 12px。
- 日期没填统一写“未填日期”，用灰色而不是警告色。

## 隐私

- 设置 → 隐私与本地处理：文字识别、分类和去重都在这台电脑上完成，不联网、不上传；识别摘录只存在你的数据文件夹里。
