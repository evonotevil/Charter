Charter 5.5.4：修正“不加水印”时“清除文件信息”不生效的问题。

## 5.5.4 更新内容

- 修正：选择“不加水印”并勾选“清除文件信息”时，导出的 PDF 仍保留作者、标题等信息，图片仍保留拍摄信息。现在清除与是否加水印无关。
- 只清除、不加水印的图片单独重新编码，去掉拍摄信息。
- “清除文件信息”选项卡会注明将清除几份；带电子签名（不加水印时）、加密的 PDF 和 Word、Excel 等文件不会清除。
- 目录 PDF 新增“文件信息”一节，列出已清除的份数和每份未清除文件的原因。
- 新增测试：不加水印 / 加水印 × 清除 / 不清除，以及带电子签名的 PDF。
