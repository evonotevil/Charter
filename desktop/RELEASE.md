Charter 5.5.0：材料包可以加水印，并修正全应用不符合设计系统和组件库的地方。

## 5.5.0 更新内容

### 材料包水印
- 准备文件包时可打开“加水印”（默认关闭），只处理导出的副本，原件不变。
- 水印文字由标签（日期、文件名称、公司名称、材料包名称、接收方）和自定义文字组成，可拖动或左移调整顺序。
- 中文 / English 切换：英文日期写作 10 Nov 2026，文件名称用英文类型名。
- 样式：斜向平铺、居中大字、页脚一行；浓淡 1–100%、字号（按页宽百分比）、倾斜角度、颜色（预设或自定义）。
- 可选压平（默认关闭）：每页转成图片再合成水印。
- 每份文件可单独决定是否加水印；带电子签名的 PDF 默认不加，需确认；加密 PDF、Word、Excel 原样放入并在目录里注明。
- 实时预览，可按文件、按页翻看；窄窗口改为“清单 / 水印 / 预览”三个标签。
- 可清除文件元数据；显示预计大小；导出途中可取消。
- 设置按用途记住；接收方每次导出时确认，并写进文件名，例如 `远澜控股（香港）_银行开户_汇丰银行_20261110.zip`。
- 目录不加水印，另列“水印”一节说明每份文件的处理方式。
- 公司页“文件”标签新增“材料包发送记录”，可打开文件或按同样设置再导出。
- 随包附带思源黑体（Noto Sans SC，SIL OFL 1.1），Mac 与 Windows 上水印和目录字形一致。

### 设计系统与组件库
- 禁用状态统一使用 `--disabled-*` 令牌（按钮、复选框、开关、下拉框），不再整体降低透明度。
- 新增组件：ProgressBar、Note、Slider、ColorSwatch；全应用的进度条和提示条统一使用它们。
- 股权结构图节点改为分组语义（修复嵌套可交互元素），法域徽章改用 JurisdictionBadge，对比度达标。
- 上传区插图、结构图 PNG 导出、提示气泡阴影改用设计令牌，深色模式正确。
- 内联字号统一到字号阶梯，内联圆角改用 `--r-*` 令牌。
- 输入框只保留 `.field` 一种样式；状态标签统一为 Pill。
- 文件行操作按钮统一为次要按钮；日期列不再使用等宽字体。
- 目录 PDF 改用设计系统配色。
