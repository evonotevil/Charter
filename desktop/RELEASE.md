# Charter 5.5.8

- 在申报日历中点错「完成」后，可在底部提示出现的 5 秒内撤销。连续完成两项会从第二项重新计时，撤销会恢复第二项。期间可以照常复制邮件。
- 首次打开文件页时会优先绘制可见的文件行。股权结构图会累加触控板连续输入的位移，快速滑动时也能跟上手势。
- 文件详情可用左右箭头逐页查看 PDF，首页和末页会停用对应的箭头。翻页时右侧表单停在原处。文件列表的「打开原件」会用系统应用打开文件。
- 准备文件包时，清单和目录预览并排对齐，长目录可独立滚动。新建用途支持全选和取消全选。切换水印时，右上角的步骤会随之展开或收起。
- 修复 macOS 上恢复完整备份时，文件名中的反斜杠被误判为无效路径的问题。
- 从 5.5.8 起，在「关于与更新」发现后续版本后，点击「下载新版本」会直接下载适合这台电脑的安装包。
- 改善了浅色、深色和窄窗口下的状态标签、输入提示和长名称排版。折叠 Mac 侧边栏时会为窗口控制按钮留出空间，停止滚动后滚动条会淡出。

Mac 安装包分 Apple 芯片和 Intel 两种。Windows 提供 x64 安装版和免安装版。下载文件的 SHA-256 校验值见 `SHA256SUMS.txt`。
