# Charter 5.5.7

- 在证据关联里，可以连续选择多家公司、人员、任职和持股，最后一起保存。持股或任职记录提供的核实依据可直接回到原记录查看。带着未保存的修改离开时，可选择保存、放弃或继续编辑。
- 设置中的档案清单支持用名称或代码选择多个法域。公司文件、人员文件及自定义条目共用「取消」「保存」。新建条目后取消详细编辑，会保留刚添加的条目。
- 合规规则可以多选法域和公司类型，显示适用公司数和自动保存状态。写入失败时可以重试。
- 人员与中介、档案清单、合规规则、集团、申报日历和股权结构调整了双栏布局。日历的邮件与完成操作、股权详情的关系操作在滚动时仍可使用。
- 外观移到「设置 → 常规 → 外观」。设备与同步集中显示档案位置、共用状态及提醒设备；当前版本放在「关于与更新」里。
- 开关、复选框和申报完成按钮采用同一套厚底按键样式。上传材料入口使用向上箭头。
- 修正单家公司概览卡片和文件包水印预览的对齐，改善入门教程的按钮在较矮窗口和可拖动区域内的点击体验。

Mac 安装包分 Apple 芯片和 Intel 两种。Windows 安装包适用于 x64。校验值见随安装包提供的 SHA256SUMS.txt。
