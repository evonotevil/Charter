Charter 5.5.6：多台电脑共用开关、入门教程，文字识别更快。

## 5.5.6 更新内容

- 新增：设备与同步 → “多台电脑共用”。开关按数据文件夹的位置显示：在 iCloud 云盘或 OneDrive 里就是开启，在这台电脑上就是关闭。
  - 关闭时，把同步盘里的档案复制到这台电脑并改用副本，同步盘里的原文件夹原样保留。复制前先下载只在云端的文件；复制期间其他电脑有修改的会补上；取消或失败时删除已复制的部分，档案不受影响。
  - 关闭后，这台电脑不再检查同步状态、不再监听文件夹，到期提醒由这台电脑发出；原来由这台电脑负责的提醒交给其他电脑。系统日历改用“Charter（本机）”，不与其他电脑的日历互相覆盖。订阅了日历文件的，完成后可以复制新路径重新订阅。
  - 开启时，可以把这台电脑的档案复制到同步盘，或改用同步盘里已有的 Charter 档案。
  - 所选位置本身在同步盘里时（例如 Mac 开了“桌面与文稿”同步，或 Windows 的“文档”由 OneDrive 接管），会说明原因并停下。
- 新安装默认把数据文件夹放在这台电脑上：Mac 为 ~/Library/Application Support/Charter/Data，Windows 为 %LOCALAPPDATA%\Charter\Data。已经在使用同步盘里 Charter 文件夹的，升级后照旧使用原文件夹。
- Mac 上的 OneDrive（~/Library/CloudStorage/OneDrive-…）也会被识别为同步盘。
- 新增：入门教程。第一次打开、数据文件夹还是空的时，先用一套虚构的示例档案演示界面和常用操作，共 8 步，可以上一步、下一步或跳过。演示中的修改不会保存；结束后回到空白档案。设置 → 关于与更新里可以重新看。
- 优化导览切换。点击「下一步」时，页面与高亮位置一起更新，说明卡不会在定位前跳到屏幕中央。
- 文字识别更快：扫描版 PDF 的多页一次识别，不再每页启动一次识别程序；识别用的页面图像改为更小的 JPEG；PNG、JPG 照片直接识别，不再先转换格式。识别时显示“正在识别第 2/4 页”。
- 设置里“新建集团”“新建条目”“新建用途”“新建规则”按钮与下方卡片右侧对齐。
